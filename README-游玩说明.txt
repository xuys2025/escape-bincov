逃离滨科夫 · Escape Bincov · v0.2.0

开始游玩
1. 解压 ZIP 到固定文件夹。
2. 用电脑端 Chrome 或 Edge 打开 start the game.html。
3. 点击「进入水产站」，在「整备」中检查武器、弹药和医疗用品，再点击「出击」。

需要浏览器支持 WebGL；不支持时页面只显示提示，不进入游戏，存档不受影响。
出击可选沿海街区或滨湾商场。原沿海封锁区已关闭，之后重做；之前没打完的封锁区行动仍可在标题页继续。

这个 HTML 已包含完整游戏，可单独分享，无需安装或联网。
若双击后打开了编辑器，请右键文件 → 打开方式 → Chrome 或 Edge。
手机触控候选版：整备支持横竖屏，战斗需要横屏；iPhone/Android 真机验收待补。

手机操作
左盘移动/外圈冲刺，右盘内圈瞄准/外圈连续开火，松开即停。
使用屏幕按钮交互、治疗、换弹和切换武器（按钮上写的是要换成的武器）；撤离区内停稳并按住「交互」3 秒。
背包或安全箱里的补给：打开「背包」，选中后点「使用」；「治疗」只使用背包中的绷带或急救包。
附近有几个箱子或尸体时，点列表里的名称选中，再点「交互」打开；散落物走近后点「交互」拾取。背包和地图面板不暂停行动。
点选物品完成库存操作，背包顶部关闭或切换安全箱；移动格位可以取消。
长方形物品可点「旋转」，放不下时点选虚线格位确认，取消保留原位置。
旋转屏幕、切到后台会暂停，回到游戏后点击继续。

桌面操作
WASD 移动；鼠标瞄准；左键攻击；右键精瞄；Shift 冲刺。
行动中 R 换弹（使用背包中的弹药）；拖动物品时 R 旋转预览，Esc 取消拖动。
1 主武器；2 水手匕首。
靠近箱子/尸体时，滚轮切换列表中的高亮目标，E 打开；关闭搜刮后再选其他目标。
空来源显示“已搜空”，仍可放回物品；同名尸体用序号区分。
没有箱子/尸体提示时，E 拾取散落物或阅读。
在本局绿色撤离圈内站稳，按住 E 满 3 秒撤离，撤离操作始终优先。
Q 使用背包中的绷带或急救包；除藻药剂需在背包中选中并点击「使用」。
Tab 打开或关闭背包；M 打开或关闭地图。这两个面板不暂停行动。
Esc 关闭当前面板；没有面板时暂停行动。

每局限时 10 分钟。出击 4 分 30 秒后电台预警，5 分钟时潮位变化。
浅滩会随潮位开放或被淹，高架路与海堤始终可通行。涉水会积累污染。
成功撤离保留装备和物资；死亡、超时或放弃会丢失背包物资和主武器，
安全箱内的物品和水手匕首保留。

箱子与尸体搜刮
靠近后按 E 打开：左侧是来源，右侧是背包和安全箱，拖到指定格才转移，也可放回。
拖到同类堆叠时只转移能装下的数量，余量留在来源；也可选择数量后拆分摆放。
长方形物品可旋转；不自动找空格或交换，取消、放不下或保存失败保留原物品。
来源物品先收入角色物品栏才能使用。
手机复用选物品→移动格位→旋转预览或点目标格；可横向滚动物品栏。
搜刮时角色停止移动和攻击，敌人、计时和潮汐继续运行；按 WASD 立即退出搜刮并开始移动，同时按住 Shift 则冲刺。
顶部常驻生命、流血/污染和倒计时；敌人命中会提示，保持搜刮界面。
E、Tab、Esc 或关闭按钮退出，M 切地图；退出后先松开原来按住的按键和鼠标。
刷新会恢复最近成功保存的行动及容器余量；新行动结束后不保留空箱或尸体。

商店与行动提示
商人物品先放进待买区，仓库物品放进待卖区，再按净金额统一结算。
待买放回商人、待卖放回仓库可取消；离开商店会确认是否放弃未结算清单。
背包和安全箱物品先移入仓库，再出售；任务物资卖后不足交付时会再确认。
出击旁提示缺少的装备、适配弹药和止血用品，仍可轻装出击。
从暂停菜单打开指南，关闭或 Esc 返回暂停；点继续恢复行动。
地图里选择本局撤离点可显示方位和直线距离（地图格），道路与潮位需自行判断。
任务栏默认收起；“仓库”统计仓库，“携带”统计背包和安全箱，包含出门带上的物资。
不单列新拾取数量；任务仍回水产站交付。
敌人实际命中时边缘短暂提示方向，多个方向可同时出现；流血、污染不显示方向。
新街区行动有近身掠夺者、枪手和望风者样板：攻击准备时会锁定方向，枪手有有限弹药与换弹空隙，望风者只通报附近同组成员。利用遮挡脱离，敌人会搜索最后目击位置后返回；近身掠夺者亲眼看见你上楼时可能沿原入口跟来。进行中的旧行动保持原规则。

存档与备份
进度保存在当前浏览器中，分享包不包含任何玩家存档。
新版行动刷新或关闭后，可从主菜单继续最近成功保存的进度，少量未保存内容可能回退。
没有世界快照的旧版行动仍按失败处理。暂停菜单可导出完整行动备份。
更换浏览器、游玩地址或 HTML 路径前，在「水产站」页点击「导出存档」。
在新入口点击「导入存档」恢复。导入会覆盖当前进度，两个存档不会合并。
清理浏览器数据可能删除存档，请提前导出备份。
想从头开始时，在水产站院子的「菜单」选择「清空存档，重新开始」：会先下载备份并在本机另存一份，之后可用「恢复清空前的存档」找回。

遇到「结算尚未保存」时，可重试保存或下载包含本次结果的结算备份。
保存成功或确认备份下载完成前，不要关闭或刷新页面。
结算备份可在「水产站」页导入，同样会覆盖该入口现有的进度。

已有玩家应使用原浏览器和固定文件路径游玩，不要从 ZIP 预览的临时路径启动。
升级前先在旧版导出存档并确认下载完成，再把新版 HTML 覆盖到原路径，用原浏览器打开。
不支持导出的 0.1.0 旧版需先在原路径升级，再导出；不要先移动或删除原文件。
新版会接续可用的旧进度，并保留迁移前原始记录。旋转后的进度与新备份需要新版读取。
旧 HTML 会拒绝读取新版记录，不会将其当作空档覆盖。
从源码构建（pnpm build）得到的 dist/index.html 也能独立游玩；已有进度可继续从原路径打开。

当前为单人游戏，手机触控处于候选验收阶段，尚无手柄、多人联机或云存档功能。
画面与声音由游戏代码生成；PixiJS 等组件的许可声明已内嵌在 HTML 中。

行动中武器卡底部显示当前枪械暴击率；屏息狙击蓄力时显示进度和锁定敌人的合并概率。
整备页点「走进水产站」进入安全基地，WASD / 左摇杆走动，靠近设施交互。

保存失败先重试或导出完整备份；旧HTML不能读取新扩展档案。
