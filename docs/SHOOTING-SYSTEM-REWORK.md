## 问题依据与计划

现有游戏已有鼠标指向、固定随机散布和立即生效的右键精瞄，但缺少累积武器后坐、移动/急转后的稳定、连射散布增长与停火恢复。镜头和准星的动画不能代替真实弹道控制。

前期资料固定引用 `a3ff52422622ffd72d0ebe79a1f0d01786dfa375` 的[完整调研](https://github.com/xuys2025/escape-bincov/blob/a3ff52422622ffd72d0ebe79a1f0d01786dfa375/docs/gunsmith/SHOOTING-FOUNDATION.md)与[实测摘要](https://github.com/xuys2025/escape-bincov/blob/a3ff52422622ffd72d0ebe79a1f0d01786dfa375/docs/gunsmith/evidence/shooting-20261012/diagnosis.json)。这些是旧机制诊断，不是新射击的验收结果。

1. 对齐鼠标、准星、视觉枪口、持枪高度、逻辑弹丸与碰撞，覆盖八方向、近墙、门窗及相机变换。
2. 建立腰射/精瞄、移动/急转/停步的准确度和稳定过程，参数由样板实测确定。
3. 将影响真实发射方向的后坐与随机散布分别管理，验证连续开火积累和停火恢复；基础枪仍应好用。
4. 按枪型定义单发/自动与取消语义，双端共用射速规则。旧三枪保留定位，加一把计划内自动枪（优先 M4A1）作临时样本。
5. Runtime 发布稳定、准确度、后坐状态；Opus 自主决定准星、持枪、镜头、触屏和声音，不限制技术栈与效果。
6. 新旧局内共用射击计算，保留角色状态、离线、弹药来源、暂停及存档事务；刷新、换层或切枪不能免费清除控制代价。

先用少量临时参数比较轻快/稳定配置，再接真实游戏与恢复流程；测试样本不进入正式经济和玩家存档。完整改装、目录扩量及批量制图留给 #28。
