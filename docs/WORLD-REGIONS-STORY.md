## 1. 世界背景与盐度

滨科夫是一座工业、居住与港运并存的虚构沿海县城。台风过后，海水没有正常退去。一种被当地人暂称为**“潮水”**的异常开始侵蚀县城。

涨潮会淹没连接县外的低洼国道、桥头和堤道，使县城成为物理意义上的孤岛。只有偶尔落潮，道路才重新显现；暴露的路面可能损毁，下一次涨潮也可能提前到来。外界仍然存在，救援、补给和撤离必须抓住有限窗口。县内大部分高地街道、建筑和工业道路保持干燥。

灾后第十七天，滨科夫水产站仍维持着照明、净水和电台。玩家是一名普通幸存者，从这里寻找补给和出路。最初的目标是活到下一次落潮，长期目标则是维持避难点、预测一次足够长的退潮，让愿意离开的人获得机会。潮水的范围正在扩大，能够离开的窗口越来越短。

潮水具有真实的超自然性质：盐化区域会出现不属于当前时间的声音，部分生命发生异常变化。来源暂不揭晓，先通过具体影响与可核实线索建立规则。参考《潜行者》的异常禁区与碎片调查、《逃离塔科夫》的封锁经济与利益冲突、《ZERO Sievert》的据点求生节奏；组织、人物与具体剧情使用本作原创设定。

### 1.1 盐度

**盐度**是人体受到潮水影响的累积程度，对应禁区生存游戏中的辐射指标，不等于普通海水的含盐量。直接接触潮水、吸入异常盐尘、使用污染物资、接触危险样本或被潮蚀生物攻击，都可能增加盐度。

短期暴露可通过净水、药物和医疗处置缓解；长期高盐度可能留下难以逆转的变异。初期可见口渴、盐斑和听觉异常，严重时出现组织结晶、感官改变与对潮水的依赖。部分变异者获得耐受力或感知能力，但效果与代价不稳定，不承诺可自由挑选能力。

宗教团体守潮人把主动接触潮水称为“受盐”，相信盐的力量能够让人适应新世界。有些成员庇护受盐者，有些强迫他人参加仪式。潮蚀生物属于异常生态，不是拥有统一政治目标的阵营；守潮人了解部分习性，但不能统一指挥它们。

叙事中使用“盐度”；当前代码与既有 RPG 文档仍使用“污染”。本轮不改字段、药品名称、数值、阈值、存档或技能。后续实施必须单独决定指标迁移与兼容，不能根据本文直接替换旧数据。

### 2.1 减少水元素的设计约定

- 内陆地区以干燥通路为常态，分别用医疗隔离、废楼坍塌、工业路障、盐尘污染和据点控制制造差异；不把每张地图做成积水街道。
- 实验室危险来自污染设备、试验残留和异常盐晶，不使用大面积淹水作为核心机关。医院旧址不是潮蚀怪物独占的鬼屋，拾荒者的生活、交易和防御痕迹必须可见。
- 商场沿用[既有两层布局](MALL-VALIDATION-MAP.md)，局部潮汐低地不扩大到整栋建筑；观测站、泵房和港口保留与水有关的功能。
- 国道的县内探索路段与县外地峡分开：前者可长期探索，后者只在主线长退潮条件满足后作为县外出口。
- 灯塔山体在涨潮后仍露出海面，低位连接道可能中断；货轮进水限于破损下层。非最终行动须保留可预判的返站路线。

## 3. 势力关系

| 势力 | 核心诉求与版图 | 合作与冲突 |
| --- | --- | --- |
| 水产站互助会 | 维持供电、净水、医疗与补给，建立安全出路；以水产站和街区联络点为核心 | 与医院、工厂合作，向盐枭购买物资，与封锁队交换情报；接纳能正常生活的变异者引发内部分歧 |
| 沿海封锁队 | 控制退潮通道，组织有限撤离，限制污染外扩；掌握国道检查站、港口入口和观测站主楼 | 与互助会合作，打击偷渡；高盐度人员通行限制与医院救治职责冲突 |
| 盐枭 | 利用运输、燃油与路线情报获利；串联市场冷库、商场卸货区、港口和货轮甲板 | 向各方出售物资，和封锁队交火，替守潮人运货；有愿意救人的船主，也有隐瞒风险的掮客 |
| 守潮人 | 相信受盐能够适应新世界；以灯塔为中心，延伸至旧观测区、货轮深舱与街区祈祷点 | 温和派提供庇护，激进派强迫受盐并阻止撤离；与封锁队敌对，拉拢互助会中的绝望者 |
| 自由拾荒者 | 搜集物资、赚取报酬或寻找出路；集中于街区、医院旧址、商场和国道 | 没有统一领袖，团体间交易或冲突；医院旧址的掌控者以病例和药品争取谈判地位 |

工厂自治队、医院医护与实验室安保作为地方组织使用，首版不为它们增加三套完整声望系统。老栓负责装备与维修物资，许医生负责医疗与盐度研究，小蔡负责供电与电台。现有敌对拾荒者属于掠夺团体，不代表所有拾荒者；现有守潮人敌人可对应激进武装成员，不代表温和派必然敌对。

各方控制具体设施而非整张地图；区域内保留空白与争夺地带。冲突集中在商场配给、工厂设备征用、医院救治、港口运输和国道撤离资格。

## 4. 长线主线：“等海退去”

六阶段，每阶段三个关键任务节点，共十八个；节点是内容规划，不是已存在的任务 ID。各阶段以少量可重复补给委托支撑据点成长，不靠反复刷同一件稀有物品拉长流程。任务主要采用收集、调查、交付、修复和成功带回情报；首版不要求护送 AI、动态战争或县城模拟。

| 阶段 | 三个关键任务节点 | 区域与成果 |
| --- | --- | --- |
| 1．站里还有灯 | 收集供电零件 → 恢复水产站供电 → 从工厂外围带回维修与通信资料 | 街区、市场、工厂外围；沿用「让灯亮起来」，建立求生据点和补给联系 |
| 2．第一次找路 | 找回国道记录 → 实地确认地峡与检查口 → 取得清障和运输设备清单 | 国道、工厂；确认出口存在，但道路受损，落潮不等于能够安全通过 |
| 3．身体里的盐 | 带回封存样本供医院检测 → 与旧址拾荒者交涉取得旧病例 → 从商场取回配给及医疗记录 | 观测站、县医院、旧址、商场；沿用「瓶中的潮声」，发现盐化早于台风，揭示受盐者的医疗与通行处境 |
| 4．第七艘船 | 带回港口船册 → 登上远汐号核对货单和打捞日志 → 解锁并调查隐秘实验室 | 港口、货轮、实验室；沿用「未归的第七艘船」，串起打捞、运输、试验及灯塔转移记录 |
| 5．退潮之前 | 修复观测设备取得窗口预测 → 在工厂与医院备齐运输和医疗物资 → 清理国道并协商撤离名单 | 观测站、工厂、医院、国道；建立集体撤离条件，直面设备、配给与通行争议 |
| 6．长退潮 | 核实长退潮信号 → 完成所选路线的最后行动 → 交付结局与幸存者去向 | 灯塔、国道、水产站；收束为逃离、封潮或留守 |

### 4.1 关键真相与线索边界

生存链为“工厂维修与运输—商场及市场补给—医院救治—水产站组织”。异常链为“港口打捞物入境—货轮运输—实验室研究—医院旧病例—灯塔异常物体”。两条线最终在撤离准备中汇合。

「远汐号」是可探索的货轮，**不是**港口船册中的“第七艘船”。第七艘船保留为失踪船线索，通过船册、航运日志与实验室接收记录定位秘密运输；不继续采用必须由活人引航的超自然摆渡船设定。

实验室掌握部分潮水规律，试验曾放大盐化影响；它没有创造潮水的全部异常。后来转移到灯塔的物体能够放大当地潮水、干扰退潮窗口，但不是最终解释一切的答案。医院旧病例作为灾前影响的独立证据，与实验室资料相互印证。

### 4.2 三个结局

| 结局 | 最后行动 | 结果与代价 |
| --- | --- | --- |
| 逃离 | 利用长退潮，让准备就绪的居民沿国道离开 | 玩家逃离县城，潮水仍存在；未撤离者继续留在滨科夫 |
| 封潮 | 让队伍先走，玩家进入灯塔切断异常联系，再赶往最后出口 | 大规模异常涨潮受到抑制，玩家承担失去退路的风险；正常海潮、既有变异和生态损害不会立即消失 |
| 留守 | 保留观测、净水和医疗体系，选择留在水产站持续接应 | 为无法离开或选择留下的人建立长期生存空间，放弃本次离开的机会 |

三个结局均由玩家明确选择。首版通过任务记录与结算文案呈现后果，不引入复杂声望结局公式、动态人口模拟或结局后无限剧情。普通行动撤离表示返回水产站，只有主线最终撤离表示离开滨科夫。

## 5. 分期、现有实现与验收边界

基线已经提供经典沿海区域、沿海街区和滨湾商场选择，建筑楼层与 RPG 系统也已进入 main，具体状态见[实施记录](PR16-IMPLEMENTATION.md)及[验收登记](PR16-ACCEPTANCE-REGISTER.md)。经典沿海地图仍含市场、观测站、旧港与泵房；不能把本文的十二区域分类当作十二张已实现地图，也不能直接拆改旧检查点。

- 第一批内容以已有街区、商场为基础，新增医院旧址和国道，完成求生与找路任务；不重复重做已有商场系统。
- 第二批增加县医院与工厂区，形成医疗、工业和盐度调查线。工厂外围可先作为第一阶段任务的局部内容开放。
- 最后补齐实验室、货轮与灯塔，整合现有沿海片区，完成异常调查与三结局。各批是内容优先顺序，实际开发须另行明确授权，不自动拆出多条实现线。
- 旧三任务的名字、物品 ID、已完成进度和奖励保留；本轮不改变其现有地点，未来接入主线需兼容已有完成状态，不重复发奖。
- 主线已成功交付的进度保留；遗失的关键物品可重新取得。实验室入口由固定调查进度解锁，不依赖低概率掉落。
- 每个出击区域至少有两条有意义的探索路线和一个明确主线目标。非最终行动不得随机封死所有返站出口，也不得把十分钟行动限制写成县域自然潮汐的统一周期。
- 县医院的诊疗与交易空间应明确可辨，不能默认所有医护敌对；旧医院必须体现拾荒者控制、交涉与生活痕迹；各区域势力首版固定，以对话、资格和局部遭遇表达变化。
