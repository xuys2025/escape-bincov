## 所有槽位共同遵守的显示规则

1. 显示条件必须同时满足任务卡的章节、地图、地点和前置；单段省写前置不构成绕过。后期地图没有开放时只展示地区未开放信息，不给出可执行入口。任务完成后走 repeat/历史回顾，不重新提供 ready、发物或领奖选项。
2. 正文与选项读取不改变状态。offer/progress/retry/repeat只读；ready与确认对话只预览。明确选择后，经条件复验和成功提交，才显示complete或对应结果。“状态效果”写已完成、发奖时，描述同一次提交的结果，绝不在显示complete时再执行一次。
3. R已有合格记录时优先ready，不能因后来失败进入“须重做巡检”的分支。D按每一份实体核对：已经归档，或当前仍持有成功带回的合格副本，才可计入齐备；仅有历史资格、实体已丢不能交付。进度、重试和领取都遵守唯一副本规则。
4. 占位符必须取本次实际清单：`{交付清单}`只列待交部分；`{已保存成果}`区分亲见、别人说过、归档和已报告；`{接替职责}`含站点、责任人与资质；`{携带人}`是唯一实际保管人。缺项不能填空却仍提供确认。
5. 交接事实与当前有效安排分开。任务已完成和已扣物资不撤销；接手人后来改为出县，只使对应责任待补办。复看旧交接只能说“当时签过”，不能把历史确认当成当前仍有人接班。若已知结局或现场变化，以结果回顾替代早期现场断言。
6. br08按**已经向小蔡报告**的总闸/喊声分支；观察到而未报告不能越过NPC知情边界。br11-00是独立位置谈话，完成校准不自动执行。br15-02引见可提前保存H；用途说明、等待、阀门和高地确认仍属于本次F，不能由旧引见自动完成。
7. 最终结果先确定一套可成立的快照，再选三路线正文之一、证据段之一、各人物结果之一。同一人仅一个结果；未知近况使用G04共用规则的线索回顾。人物/证据段均不另写档、不再次交付。已保存结果回顾不读取后来变化的世界重新算结局。
