## 任务卡共用规则

以下规则是32张卡的组成部分。卡片必须指定对应规则，不能用“默认处理”省略失败语义。

| 代码 | 目标与保存点 | 死亡/超时/放弃 | 刷新、重试与交付 |
| --- | --- | --- | --- |
| K 见闻 | 成功调查时与世界共同提交，永久记录“看见/听见过” | 已提交见闻保留；未提交的不保留 | 恢复最近成功检查点；重访可读，不重复奖励 |
| R 同局巡检 | 卡片指定的观测点（sq01/02各两点）＋本局成功撤离才生成合格记录；返站主动报告完成 | K见闻保留，本次巡检资格清除，下局重做指定点 | 刷新续原尝试；检查点记录已查点；合格记录一旦结算保存，不因下一局失败消失 |
| D 物证带回 | 持有指定副本并成功撤离，之后回站归档；取物、容器余量同事务 | 普通背包丢失；安全箱副本保留，但本次失败不取得“成功带回”资格 | 未合格副本可下次携出并成功带回；已合格副本丢失须重取并带回。只对新专用物证记录资格，不给所有旧物品增加来源限制 |
| B 现场施工 | 工具卷在背包，材料在背包，连续操作5秒；移动/受击取消，不扣料；完成时扣料、写设施事实和世界状态 | 已成功提交的施工保留；未施工材料按所在容器处理；返站报告可等下一次 | 刷新恢复已施工状态，未完成的5秒从头开始；重访不重扣。现场完成后即使该局失败，返站仍能报告 |
| H 交付/明确确认 | 在卡片指定地点预览消耗、条件与结果，明确提交；缺件整笔拒绝 | 已提交步骤保留，不因后来失败消失 | 写失败全部回滚；重试不重复发奖/扣物；未提交退出不作选择 |
| G 配装验收 | 站内展示一把合法实物枪，实时判条件；枪与配件不交出，确认后记一次完成 | 枪在以后行动仍按原规则损失；已完成委托不撤销 | 不看保存预设/截图；不吞装备枪，不复制枪，不接受含救济来源的枪或配件；重复展示无奖 |
| F 最后行动 | 路线和人物安排明确确认后进入一次独立尝试；详见逻辑文档 | 失败不显示成功结局、不结算人物死亡；保留已提交的非最终准备，允许重整备重试 | 活动刷新恢复；最终动作与结局共同结算，成功后仅回顾。封潮失去退路属于成功路线后果，不能当玩家死亡失败 |

所有操作沿唯一主档原子事务。写前失败回滚；已写入后发布失败保留已提交结果，要求恢复，不再次扣料或领奖。UI读取不计数；同一实体、跨层重访、重复请求不重复计数。完成反馈在成功写入后出现。新任务奖励仅现金/事实；满仓不会导致现金丢失，物证归档前必须先实际持有。

H在BASE时须非行动中，可校验仓库/背包/安全箱；原三任务与新现金奖励只在此交付。未来HOS/FAC等现场H属于待实现的NPC交涉：必须真实到达安全交涉锚点，只能扣身上背包/安全箱物品，不能远程扣仓库；世界不暂停，危险/离开可中断未提交谈话，已提交结果保留。D是“取出后带回”的物证规则，不套在从基地携去医院的临床分样上；分样按现场H消耗。
