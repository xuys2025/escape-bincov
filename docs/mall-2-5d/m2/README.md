## 接入布置表（2026-10-28）

- 家具：[`mall-dressing.ts`](../../../src/coast-view/mall-dressing.ts) 的 `mallProps` 给 26 种四版家具先选本批素材，程序绘制件排在后面作后备（素材全部加载成功时不会用到）。连排件按左右邻居选 `end-w` / `end-e`，两侧都没有同类时选 `single`，中间按格子在 `mid-a` / `mid-b` 间交替；墙架和柜台按所在店铺选外观，其他店铺用零食架和普通柜台。玻璃柜台、售货机、配电柜按本体位置叠加同名遮罩的发光；售货机仍有自己的一点灯光。
- 投影底座：多数素材填满占地，投影和接触暗线按占地画，场景再按图的实际底边和左右范围收窄。比占地窄的五种按图量了底座（`DRAWN_BASE`）：人台的圆底座、衣架两端的脚、快餐桌和四张凳子、滑梯、竹屏风中线。原来给程序件定的售货机、文件柜、保险柜、空调外机、垃圾箱、车和收银通道的窄底座不再用。
- 地面（只在四版生效，一至三版不变）：仓库、配电间、服务间、电房、二层仓库与服务通道用水泥地；办公室和财务室用地毯；儿童乐园用橡胶垫；厕所用小方砖；南街和卸货区用沥青。区域重叠时按最内层的房间选（二层电房在儿童乐园里面，铺水泥不铺橡胶垫）。地面材质的磨损着色跟着换：水泥和沥青按对应材质。
- **四个模块暂不使用**（`SAMPLE_STAND_IN`），等 Sol 重新导出：快餐柜台的 `mid-b` 东侧和 `end-e` 西侧、洗手台的 `mid-b` 东侧各有一条 4–6 像素宽的透明竖缝，碰撞是连续的，画出来却像能穿过的缝；`end-e` 的台面也比其他段矮一截。仓储货架的 `end-e` 左侧约 10 列是导出时拉出的横向花纹。前三个由同类型的 `mid-a` 代替（快餐柜台东端因此不收口），货架东端改用 `single`（两侧都有立柱）。见[连排对照](stand-ins.png)（4 倍，左起 end-w、mid-a、mid-b、mid-a、end-e）。货架和炸锅线的 `mid-b` 东侧是一条不透明的深色竖条，看上去像隔开的两格，没有误导通行，暂时照用。

## 原图与可重复导出

创作使用内置 **image_gen**，40 张原图（38 张当前采用的图集/单件图，另有竹屏风、儿童垫两张修订前原图）保留在 `assets/mall/sources/m2-p0/` 至 `m2-p3/`。四批完整提示词见上表；每批 `p*-sources.json` 保存原图哈希与共用调色板。没有使用 CLI/API fallback。

导出只做确定性的裁切、最近邻采样、顶面/正面基准对齐、硬透明、共用调色板及接缝归一。柜台端头原图有偏高围板，普通段从密集台面行裁切；单件保留收银机。售货机灯条比一个缩小采样间隔窄，导出时在对应像素区域保留原图实际存在的最亮灯像素。发光遮罩只提取本体已有的亮色灯条，没有外部光晕。

从仓库根目录运行：

```bash
node docs/mall-2-5d/m2/export-p0.mjs
node docs/mall-2-5d/m2/export-m2.mjs p1
node docs/mall-2-5d/m2/export-m2.mjs p2
node docs/mall-2-5d/m2/export-m2.mjs p3
node scripts/mall-assets.mjs
node docs/mall-2-5d/m2/validate-m2.mjs
node docs/mall-2-5d/m2/review-m2.mjs
```

验证器独立读取 PNG 字节，并加载当前 `MALL_FURNITURE` / `PAINTED_LIFT` 核对全部 26 种类型的占地、碰撞与 lift；还检查哈希、尺寸、alpha、调色板、锚点、矩形 B 覆盖/异形 B 范围/竹屏风特例、遮罩、54 对开口接缝及 20 组地面 A/B 周期。旧清单对照固定为接手的 PR head `60a0d938753baf12eeaa376bcf333668e0dc44cd`；浅克隆需要先取得这个提交。P0 PNG 在共享导出器下重导出后字节不变。
