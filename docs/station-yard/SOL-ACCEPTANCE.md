## 4. 写入失败与冲突

- [ ] 在开发者工具里让 `localStorage.setItem` 对 `escape-bincov.session.v2` 抛错（或把浏览器存储占满），然后修建 / 交易：操作被撤销，弹出“存档没有写入”对话框，钱和物品不变；恢复后点“重试保存”，对话框关闭；再做一次只扣一次钱。
- [ ] 训练时写入失败：对话框出现后“导出存档”下载的备份里有刚才的练习时间；恢复写入后“重试保存”能写进去，不重复计时。
- [ ] 同一个游戏开两个窗口：另一个窗口写入后，这一边的院子出现红色“存档已被另一个窗口接管”按钮，对话框只有“导出存档”“刷新页面”，任何交易都不生效；后打开的窗口在标题页就提示无法打开存档。
