# #75 H-02 分枪种枪声的证据

分支 `feat/hit-feel-sounds`，2026-10-25 本地实测（Windows，本机 Chrome 156.0.8078.48）。声音全部由游戏自己的合成代码生成，没有外部音频素材。

## 响度

在本分支构建上，用 `?test=1` 拿到游戏的 `SynthAudio`，把每一枪单独渲染进 `OfflineAudioContext`（48 kHz 单声道，不经过限幅器，主音量 1），每种渲染 3 次取平均（噪声起点随机）。“前 150 ms”是这一段的 RMS，代表枪声的冲击；“时长”是降到 −60 dB 以下的时间。

| 声音 | 峰值 | 前 150 ms | 时长 |
| --- | --- | --- | --- |
| 改动前的手枪（手枪、卡宾、M4A1 共用） | 0.581 | 0.073 | 143 ms |
| 改动前的霰弹 | 0.884 | 0.128 | 222 ms |
| 改动前的敌人开枪 | 0.345 | 0.042 | 141 ms |
| 九毫米手枪 `pistol9`（手枪） | 0.520 | 0.069 | 177 ms |
| 重弹手枪 `pistol45` | 0.530 | 0.078 | 234 ms |
| 冲锋枪 `smg` | 0.429 | 0.042 | 108 ms |
| 卡宾枪 `carbine`（卡宾） | 0.569 | 0.070 | 292 ms |
| 步枪 `rifle`（M4A1 样本） | 0.471 | 0.068 | 343 ms |
| 支援机枪 `lmg` | 0.503 | 0.073 | 235 ms |
| 精确步枪 `dmr` | 0.507 | 0.089 | 433 ms |
| 栓动步枪 `bolt` | 0.604 | 0.101 | 625 ms |
| 双管霰弹 `shotgun-double`（双管） | 0.847 | 0.130 | 481 ms |
| 泵动霰弹 `shotgun-pump` | 0.705 | 0.126 | 554 ms |
| 半自动霰弹 `shotgun-semi` | 0.684 | 0.113 | 337 ms |

游戏里现有的四把枪，前 150 ms 和改动前相比：手枪 −5%、卡宾 −4%、M4A1 −7%、双管 +2%。冲击基本不变，尾音更长，几把枪之间也能分辨。敌人开枪用各自的音色族乘 0.55，和原来的敌人枪声同一个比例。

## 试听

四段 WAV 经过游戏的输出链（主音量 0.35 和同一个限幅器），四个文件用同一个增益，可以直接比较响度：现有四把枪新旧对比、全部 11 个音色族、连射、敌人开枪的远近。文件放在临时分支 `preview/hit-feel-sounds`（维护者听完后删除），说明见那里的 README。为了不让 PR 的 CI 重跑，没有放进本分支。

游戏里也可以直接对比：试枪场面板的“打击感：新版 / 旧版”按钮，点一下，下一枪就换成另一种声音。

## 其他检查

- `test:range`：2/2 通过，包括开关切换 `ViewOptions.feel` 和按钮文字，且按开关不会开枪、不改瞄准。
- 单测：`tests/coast-sound.test.ts` 覆盖新旧两种设置下玩家和他人开枪的映射；`tests/gun-timbre.test.ts` 覆盖改枪目录 20 把枪和现有四种外观。

渲染与测量脚本是一次性的，没有提交。没有做真机或真人试听。
