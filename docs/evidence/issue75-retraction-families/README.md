## 参数

`src/coast-view/weapon-retraction.ts` 的 `RETRACTION`，按枪声音色族（`src/gun-timbre.ts`）给回缩的世界像素和时长。原来所有枪都是 3 像素 / 80 ms。

| 音色族 | 幅度 / 时长 | 现在用到它的枪 |
| --- | --- | --- |
| 九毫米手枪 | 2 像素 / 60 ms | 旧式手枪 |
| 重弹手枪 | 2.5 像素 / 70 ms | 改枪目录里的 1911（还没接入） |
| 冲锋枪 | 2 像素 / 50 ms | 改枪目录（还没接入） |
| 卡宾枪、步枪 | 3 像素 / 80 ms（不变） | 卡宾枪、M4A1 样本 |
| 支援机枪 | 3 像素 / 70 ms | 改枪目录（还没接入） |
| 精确步枪 | 4 像素 / 100 ms | 改枪目录（还没接入） |
| 栓动步枪 | 4.5 像素 / 120 ms | 改枪目录（还没接入） |
| 双管、泵动霰弹 | 5 像素 / 130 ms | 双管 |
| 半自动霰弹 | 4 像素 / 100 ms | 改枪目录（还没接入） |

每族的回缩都比该族最快的连发间隔短（单测逐把核对改枪目录的 20 把枪），按住扳机不会叠加。改枪目录里的枪要等 M2-11 让开枪事件带上枪 id 后，才会按枪查表；现在按手持外观查。

## 检查 j 的结果

在当前批次的副本上放一发玩家的子弹，换上要测的外观，停住 ticker，按 1/60 秒调用 `present()`。下表是开枪当帧之后每帧的回缩（世界像素，按整像素位置量）。

| 枪 | 本分支 | main |
| --- | --- | --- |
| 手枪（向东、南、西、北） | 1、1、0 | 2、2、1、0 或 2、2、1、1 |
| 卡宾枪、M4A1 | 2、2、1、1 | 2、2、1、1 |
| 双管 | 4、4、3、2、2、1、1 | 2、2、1、1 |
| 旧版设置、减少动态效果 | 全 0 | 全 0 |

main 上手枪向西、向北两例和双管不满足新的要求，检查失败；本分支通过。火光每例都跟着枪管 5 帧、偏差 0 像素。
