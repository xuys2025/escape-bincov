# 二十种枪械候选目录

实施排在 PR22 完成并合入 main 之后；本表是候选设计，不表示当前游戏已具备这些枪械或配件。接口、素材与验收按 [总体计划](PLAN.md) 和 [PR22 衔接](PR22-INTEGRATION.md) 执行。

2026-10-07 初版设计。正式目标是 20 种可获得、可使用、可保存改装的枪械，包含旧 3 种与新增 17 种；匕首、配装预设、颜色变体均不计数。按用户 2026-10-09 的最新要求，枪械名称直接使用原型号，旧三枪保留现有名称；计划中的内部 ID 保持不变。

## 改装入口

| 枪型 | 原厂和后续接口 |
| --- | --- |
| 旧式手枪 | A01 可提供微型瞄具位；保留旧物品 ID |
| G17 通用手枪 | 原生微型瞄具位、手枪侧挂位 |
| M1911 重型手枪 | A03 提供微型瞄具位；单排握把模块 |
| P226 稳定手枪 | A02 提供微型瞄具位；手枪侧挂位 |
| MP5 近战冲锋枪 | A04 提供顶部导轨；H06/H07 提供附件位 |
| UMP45 重弹冲锋枪 | 原生顶部、下导轨及侧导轨 |
| P90 紧凑冲锋枪 | 原生顶部及侧导轨；专用供弹模块 |
| Vector 9mm 高速冲锋枪 | 原生顶部、下导轨及侧导轨 |
| 双管霰弹枪 | A05 提供顶部导轨；专用枪口模块；固定双管供弹 |
| M870 泵动霰弹枪 | A06 提供顶部导轨；H08 提供下/侧导轨 |
| M1014 半自动霰弹枪 | 原生顶部导轨；H09 提供下/侧导轨 |
| 半自动卡宾枪 | A07 提供顶部导轨；H05 提供下/侧导轨 |
| AK-74 稳定步枪 | A08 提供顶部导轨；H04 提供下/侧导轨 |
| AK-103 重型步枪 | A08 提供顶部导轨；H04 提供下/侧导轨 |
| M4A1 模块步枪 | 原生顶部导轨；H01/H02 提供下/侧导轨 |
| AUG 紧凑步枪 | 原生顶部、下导轨及侧导轨 |
| SVD 精确步枪 | 原生顶部导轨及支撑脚架位 |
| M14 半自动精确步枪 | 原生顶部导轨及支撑脚架位 |
| M700 栓动步枪 | 原生顶部导轨及支撑脚架位 |
| RPK 支援机枪 | A08 提供顶部导轨；H10 提供下/侧导轨；支撑脚架位 |

远距瞄具资格授予 半自动卡宾枪、AK-74、AK-103、M4A1、AUG、SVD、M14、M700、RPK；其中没有原生顶部导轨的枪仍需先安装相应基座。其他顶部导轨可使用 O03–O07 和 O12，微型接口使用 O01/O02。这些限制服务于游戏清晰度与平衡。

手枪侧挂位只对 G17、M1911、P226 原生提供；微型基座不会额外生成侧挂位。支撑脚架位仅对 SVD、M14、M700、RPK 提供。

## 数量与差异要求

| 类型 | 数量 |
| --- | --- |
| 手枪 | 4 |
| 冲锋枪 | 4 |
| 霰弹枪 | 3 |
| 步枪 | 5 |
| 精确步枪 | 2 |
| 栓动步枪 | 1 |
| 轻机枪 | 1 |
| 合计 | 20 |

每种枪至少在射击节奏、弹量/装填、基础散布与恢复、负重/占格、可用改装方向中有两项可感知差异。并非要求每枪拥有全部十类配件；双管霰弹枪 的选择可以集中在宽覆盖与收束点射，M4A1 则提供更多模块选择。

## 旧存档承接

- pistol → 旧式手枪：保留旧 ID、8 发容量、基础伤害 27、射击间隔 0.29 秒及原始占格 2×1。
- shotgun → 双管霰弹枪：保留旧 ID、2 发、每发 6 枚弹丸、每枚基础伤害 15、射击间隔 0.72 秒及原始占格 3×1。
- carbine → 半自动卡宾枪：保留旧 ID、12 发、基础伤害 39、射击间隔 0.24 秒及原始占格 3×1。
- 三者其余现有基础属性及价格按旧定义迁移；迁移本身不发放新配件、不补弹、不消耗钱物、不扩充背包。
- 旧主武器也生成唯一枪械实例；原有库存枪沿用自己的 UID。同型号的不同配装不合并或互相覆盖。
