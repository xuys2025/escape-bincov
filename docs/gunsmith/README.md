# 改枪系统计划

目标是 20 种枪械、100 种独立配件，接入现有搜刮、背包、交易、十分钟行动和存档恢复。枪械使用原型号，旧三枪保留现有名称。

**2026-10-12 状态：#22 设计与 #33 实现已经合入 main，本分支已同步主线 `6450504`。当前仍为文档 PR #28，配件品牌已确定放详情；新增射击基础调研，先验证 M0-S 可玩射击样板，再推进改装。代码实现等待安排。**

2026-10-09 的“PR22 未推送/有冲突”属于旧快照，不能继续作为当前阻塞依据。现有 Runtime、院子、城中村、商店及后续修复以 main 为准；#32 的内存归因、历史异常和真机未测状态继续保留，不要求全部清零才启动新功能。开工时核对相关接口与增量回归边界。

配件主名称已去掉重复品牌和 B，例如「北堤 B 微型点瞄」改为「微型点瞄」，详情保留「制造商：北堤」。100 个编号、功能及兼容关系保持。当前游戏已有指向、固定散布和立即生效的右键精瞄，缺少真实累积后坐与动态稳定；先做可感知的射击基础，再让配件作用于这些机制。

本计划初稿为 2026-10-07；2026-10-09 更新原型号名称和排期，2026-10-12 同步主线与当前依赖。改装深度、弹药分组、数值与工期仍为设计建议。
