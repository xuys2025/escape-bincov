# 改枪系统计划

目标是 20 种枪械、100 种独立配件，接入现有搜刮、背包、交易、十分钟行动和存档恢复。枪械使用原型号，旧三枪保留现有名称。

**2026-10-22 状态：已排期。** 维护者要求把计划拆成可执行的小任务并排期，#28 合入 main 表示已排期。M0-S 射击基础已由 [#39](https://github.com/xuys2025/escape-bincov/pull/39) 完成并合入；改枪从 M0 开工，分 4 个实现 PR，预计 12-11 完成全部 20 枪、100 件（10-24 评审后提前两个工作日）。任务、负责方、估算和日期见[任务与排期](TASKS.md)，实时进度见 [#80](https://github.com/xuys2025/escape-bincov/issues/80)。
