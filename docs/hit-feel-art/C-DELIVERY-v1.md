## 制作方式

任务书要求整块挪动、复制已有像素，本批直接在原始逻辑格按部位编辑，使用 Pillow 读写非预乘 RGBA；没有经过 HTML canvas 或重新生成站立图，也没有生成模型重画、颜色量化、插值、滤镜或自动逐帧居中。新增姿态只复制同方向原图已有的 RGBA 值，包括半透明边缘。第 0 列始终从模板保留。

人形头部下移 2/1 像素，缩紧躯干；重甲的躯干变化较短，徒手及轻装的变化较大。膝部以相连裤腿的行复制形成屈曲，不向两侧拆开。持械人形第 19、20 行固定；所有角色轮廓最低四行固定，回收队长 N 和盐背犬 N 的固定带从第 43 行开始，避免只固定画布底四行而漏掉原图较高的脚底。兽形分别压壳收钳、压低头背、收缩囊腹，腿部保持支撑。

[制作脚本](author-poses-c.py) 可复现全部输出，[独立检查脚本](audit-poses-c.py) 只读保存后的文件，不导入制作函数、不修复素材：
