# 逃离滨科夫 · 游玩手册

台风与赤潮封锁了滨科夫县。你从水产站出发，搜集补给、避开危险，在 **10 分钟内撤离**，把装备和物资带回来。

已发布版本为 0.2.0，包含一张地图、三项任务和单人游戏流程。本分支另含PR16建筑、RPG、基地与商场候选，尚未发布，详见 [实施记录](PR16-IMPLEMENTATION.md)。桌面使用键盘与鼠标；手机触控开放尝鲜，iPhone/Android 真机验收待补。完整更新内容见 [v0.2.0 发版公告](releases/v0.2.0.md)。

## 开始游玩

**在线：** 用电脑端 Chrome 或 Edge 打开 [在线试玩](https://xuys2025.github.io/escape-bincov/)。首次加载需要网络，无需账号。

**离线：** 解压 `release/Escape-Bincov-portable.zip`，用 Chrome 或 Edge 打开 `start the game.html`。这个 HTML 已包含完整游戏，可单独复制或分享，无需安装、服务器或联网。若双击后打开了编辑器，右键选择「打开方式 → Chrome 或 Edge」。

建议窗口为 1280×720 或 1920×1080。主界面按窗口排布；桌面水产站与行动画面使用 960×540 逻辑尺寸，手机控件独立按屏幕排布，窗口边缘可能留有黑边。首次点击后才会播放声音，可在「水产站」页或暂停菜单调整「游戏音量」。

## 第一局

1. **整备。** 点击「进入水产站」，在「整备」中检查主武器，把备用弹药、绷带或急救包放入背包。商店买到的物资先放入仓库，需要自行转移。
2. **出击。** 点击「出击」，按 `M` 查看本局两个绿色撤离点。每局有 25 名敌人和 60 份初始物资（最多 20 份收入箱子，其余散落），枪声会引来附近的敌人。
3. **搜集物资。** 散落物按 `E` 拾取；箱子和尸体按 `E` 打开双栏，手动拖入指定格。按 `Tab` 整理背包。重要的小件可以放入安全箱。背包和地图打开时，行动继续。
4. **撤离。** 在本局绿色撤离圈内站稳，按住 `E` 满 **3 秒**。回站后可出售物品、交付任务、整理装备，再次出击。

## 手机触控候选版

整备支持横竖屏，战斗需要横屏。左盘移动、外圈冲刺；右盘内圈瞄准、外圈持续开火，松开停止；不按右盘时，角色面朝移动方向，想边退边盯住目标需按住右盘。靠近物资点击「拾取」，在绿色圈内站稳，按住「撤离」3 秒。治疗、换弹、武器切换、地图、背包和暂停均有按钮。旋转、切到后台会暂停，回到游戏后点击继续。

手机点选物品查看操作；仓库可切换列表或格位整理，不必拖动或双击。背包顶部可关闭并切换安全箱；点「移动格位」后选择虚线格位，也可取消。

PR #7 候选版增加「药品」入口，列出背包和安全箱中的药品与补给及其效果；安全箱用品只在明确点选时消耗，「治疗」仍只读取背包的绷带和急救包。多件物品在附近时，可点「附近」逐件拾取。阅读有可滚动正文，换弹按钮显示剩余秒数。地图、背包、药品与附近物品面板均不暂停行动。修复和验收边界见 [移动体验修复](MOBILE-EXPERIENCE-FIXES.md) 与 [移动实现](MOBILE-IMPLEMENTATION.md)。

## 桌面操作

| 按键 | 动作 |
| --- | --- |
| `W A S D` | 移动 |
| 鼠标移动 / 左键 | 瞄准 / 攻击 |
| 右键 | 精瞄 |
| `Shift` | 冲刺，消耗耐力 |
| `R` | 换弹，使用背包中的对应弹药 |
| `1` / `2` | 切换主武器 / 水手匕首 |
| `E` | 拾取散落物、打开／关闭搜刮，或阅读留言 |
| 按住 `E` 3 秒 | 在本局绿色撤离圈内站稳后撤离 |
| `Q` | 使用背包中的绷带或急救包 |
| `Tab` / `M` | 打开或关闭背包 / 地图，均不暂停行动 |
| `Esc` | 关闭当前面板；没有面板时暂停行动 |

按 `Q` 治疗时，流血且背包有绷带就先用绷带，否则优先用急救包，再用绷带。除藻药剂、净水瓶和鱼松罐头需要在背包面板中选中，点击「使用」。

## 箱子与敌人尸体

桌面靠近后，行动画面的搜刮提示会列出可访问的箱子和尸体；滚轮上下切换高亮目标，再按 `E` 打开。空容器标注“已搜空”，同名尸体加序号区分。选择时可正常移动和攻击，关闭搜刮后才能改选其他来源。附近同时有散落物时，可点「附近」拾取；撤离仍然优先。手机点列表中的名称，直接打开对应箱子或尸体。

桌面搜刮左侧是 6×5 背包、主武器槽和 2×2 安全箱，右侧为 6×5 来源；手机的来源在前，物品栏可横向滚动。单击查看，拖入指定空格或兼容堆叠才转移；允许放回，空容器仍可使用。来源物品必须先收入角色物品栏才能使用；枪可以直接从来源拖到主武器槽装备。

搜刮期间角色停止移动和攻击，计时、敌人、伤害和潮汐继续。`E`、`Tab`、`Esc` 或关闭按钮退出，`M` 切地图；死亡、超时、失焦暂停、存档冲突或不可访问会关闭。放不下或保存失败时物品留在原处。刷新恢复已保存的容器余量。手机复用“选物品 → 移动格位 → 点目标格”，可横向滚动查看另一侧。

可手选数量拆分后摆放；拖到兼容堆叠时只补足空余容量，其余留在来源。桌面拖动时按 R 旋转预览，手机点旋转按钮；取消、放不下和保存失败都保留原物品。不自动找空位或交换物品。生成及验证详见 [搜刮说明](LOOTING.md)。

任务栏默认收起。“仓库”统计站内仓库，“携带”统计背包与安全箱，包含出门时带上的物资；它表示当前位置，不表示本局新拾取量。任务仍需回水产站交付。地图中选择本局有效撤离点后，显示方位和直线格距，请自行判断道路与潮位。

## 潮位与身体状态

出击 **4 分 30 秒**后，电台会发出潮汐预警；**5 分钟**时，潮位由高变低或由低变高。这里指从出击开始计算的时间。浅滩捷径和部分物资会随潮位开放或被淹，高架路与海堤始终可通行。

涉水会积累污染，污染过高会损失生命。流血会持续损失生命，需要止血。医疗用品和食品的效果如下：

| 物品 | 效果 |
| --- | --- |
| 密封绷带 | 止血，恢复 16 点生命 |
| 急救包 | 止血，恢复 55 点生命 |
| 除藻药剂 | 降低 55 点污染 |
| 净水瓶 | 恢复全部耐力，降低 12 点污染 |
| 鱼松罐头 | 恢复 12 点生命和 50 点耐力 |

## 仓库、背包与装备

- **仓库**保存留在水产站的物资，初始为 10×6 格。
- **背包**为 6×5 格，其中的物资会带入行动。
- **安全箱**为 2×2 格，其中的物品在撤离失败后也会保留。
- 单击物品查看用途和操作，拖动整理位置。在「整备」中双击可在仓库与背包间转移；也可用详情中的「放入背包」「放入仓库」「放入安全箱」按钮。
- PR #7 候选版的长方形物品可在详情点「旋转」。原位置放不下时，选择虚线格位确认，取消保留原位置；自动收入或转移会尝试另一方向，不挪动已有物品。安全箱仍为 2×2，急救包和净水瓶可以一起放入。
- 同类物品可按堆叠上限合并，救济物资与普通物资保持区分。格子中的短名称与物品详情中的全名指同一物品，例如「除藻剂」即「除藻药剂」。

**负重包含背包、安全箱、主武器、水手匕首和枪内子弹。** 超过 24 kg 会减慢移动，并增加冲刺的耐力消耗。

主武器需要先装备。行动中把背包或搜刮来源里的枪拖到面板左侧的主武器槽即可装备；手机先点选枪，再点主武器槽。安全箱里的枪要先移回背包。水手匕首始终可用。换弹只使用背包中的弹药，安全箱里的弹药要先转入背包。

成功撤离会保留枪内子弹。换枪或卸下主武器时，会尝试放回原枪及其子弹；空间不够就不执行操作。救济子弹不可出售，装填、换枪和卸枪都不会改变这一点。

## 商店与任务

老栓的「修理铺」出售武器、弹药、零件和几件基础改枪配件；许医生的「卫生所」出售医疗用品和食品。左侧商人、中间上方待买／下方待卖、右侧仓库。按份加入待买，整组加入待卖，点击「统一结算」按净金额完成买卖，购买物资进入仓库；放回原侧可取消，离开时确认放弃未结算清单。缺钱、空间不足或保存失败时整笔不执行。出售统一在商店进行，背包和安全箱物品需先移入仓库，救济物资不可出售。卖后不足交付未完成任务时会列明需求、卖出和剩余数量，再次确认。

「电台任务」中的三项任务可以从仓库、背包和安全箱交付物资，交付后会扣除所需数量。

| 任务 | 所需物资 | 报酬 |
| --- | --- | --- |
| 让灯亮起来 | 泵机零件 ×3、绝缘线圈 ×2、陶瓷保险管 ×1 | ¥420，解锁仓库扩建 |
| 瓶中的潮声 | 赤潮封存样本 ×1，位于潮汐观测站 | ¥650 |
| 未归的第七艘船 | 港口船册 ×1，位于旧渔港 | ¥800 |

完成「让灯亮起来」后，可在「水产站」页花费 **¥600 扩建仓库**，容量从 10×6 格增至 10×9 格，只能扩建一次。

## 撤离失败与救济物资

成功撤离保留装备和物资。**死亡、超时或主动放弃会丢失背包内的物资和主武器，安全箱内的物品与水手匕首保留。** 新版行动关闭或刷新后，可从主菜单继续最近成功保存的进度，少量未保存内容可能回退；无世界快照的旧版行动仍按失败处理。

没有枪械时，如果现金低于 ¥200，或者把仓库、背包和安全箱里能卖的东西全部卖掉也买不起一把旧式手枪（¥320），水产站会提供救济手枪、12 发子弹和绷带。如果拥有的枪械只有救济手枪，仓库、背包、安全箱和弹匣里都没有 9 毫米弹，而且全部卖掉也买不起一包 9 毫米弹（12 发 ¥84），水产站会补发 12 发救济子弹。估算能卖多少钱时，不算救济物资，也不算未完成任务还需要的物资；佩戴中的饰品和工作台生产队列里的材料、现金与成品也不计入。救济物资均不可出售。背包或仓库空间不足时，未领到的物资会留在水产站；腾出空间后，可在「整备」点击「领取救济补给」。同一批救济物资不会重复发放，也不会在行动中自动补入背包。

## 存档与备份

进度保存在**当前浏览器**中，不是云存档。新版主记录为 `escape-bincov.session.v2`，旧 `escape-bincov.save.v1` 首次迁移后保留原始字节；未知或损坏的记录不会被当作空档覆盖。更换浏览器、游玩地址或 HTML 文件路径，可能会读到另一份进度；清理浏览器数据可能删除存档。请使用原浏览器和固定路径游玩，不要从 ZIP 预览的临时目录启动。

PR #7 候选版仍使用原存档键，读取旧版进度时保留迁移前原始记录。旋转后的进度和新备份需要新版读取，v0.2.0 页面会拒绝读取并保留原记录；不要用旧页面继续新进度。

更换入口前：

1. 结束行动，在「水产站」页点击「导出存档」，确认 JSON 文件下载完成。
2. 打开新入口，进入同一页，点击「导入存档」并选择备份。
3. 核对现金和累计出击次数，确认后导入。**导入会覆盖该入口现有的进度，两个存档不会合并。** 写入失败时仍保留原存档。

行动暂停菜单可导出包含完整局内状态的行动备份，在水产站确认导入后，从主菜单继续。遇到「结算尚未保存」时，行动已经结束，但本次结果只暂存在当前页面。可以重试保存，或下载包含本次结果的结算备份。**保存成功或确认备份下载完成前，不要关闭或刷新页面。** 结算备份也通过「导入存档」恢复，会覆盖该入口的现有进度。

另一个窗口更新存档时，本页会停止操作，防止覆盖。若当前有未保存的结算，先下载结算备份；重新加载后，选择需要保留的进度再导入，不会自动合并两个窗口的结果。

想从头开始时，在水产站院子里按 Esc 或点「菜单」，选择「清空存档，重新开始」。确认后，游戏先下载一份当前存档的备份，并在本机另存一份，再把现金、物资、仓库扩容、任务、设施、身体、成长和出击记录全部恢复为新开局，只保留音量设置；旧版迁移时保留的原始字节不受影响。之后菜单会出现「恢复清空前的存档」，经过覆盖确认即可找回。本机只保存一份：下一次清空会替换它，但当前存档若仍是没动过的新开局，清空时不会另存，原来那一份保留，完成提示也会说明。主菜单、旧版页签和无法读取的存档不提供清空；行动中、结算尚未保存或存档已被另一个窗口接管时，清空会被拒绝，原存档不变。

从旧 0.1.0 本地文件升级时，先把新版 HTML 覆盖到原路径，再用原浏览器打开并导出；不要先移动或删除原文件。浏览器禁止保存数据时，游戏会提示保存失败并阻止出击。

## 重现同一局配置

「整备」底部的「行动种子」留空时随机生成，也可输入数字或文字。相同种子可以重现出生点、初始潮位、撤离点组合、敌人和地面物资的初始配置；玩家操作仍会影响结果。

## PR16 新玩法候选

整备页「行动区域」可选择沿海街区（居民楼）或滨湾商场，两者都使用 2.5D 画面；原经典区域「沿海封锁区」已关闭，之前开始的经典行动仍可从标题页继续完成。游戏需要浏览器支持 WebGL。新街区/商场启用跨行动身体与成长；「身体」查看属性、暴击说明和限时状态。靠近门或楼梯按E/点交互，切层后先释放旧按键；地图可预览其他层，查看不换层。露台属于二层，无法操作地面物资或撤离。

「走进水产站」进入安全基地，WASD/移动摇杆走动，靠近固定设施交互，也可打开整备菜单。免费恢复不消耗补给；生产先支付材料，工作台有限队列逐批进行，成品整批领取，成品位满则停工。训练区先选项目，再实际走动练习，挂机和离线不会练级。

旧进行中海岸按原规则完成。保存失败、导入确认和备份保护继续适用；使用新版RPG档案后需新版读取。手机真机、真人经济/战斗平衡和商场原图对照仍待验收。

## 库存快捷操作

基地整备可双击物品在仓库与背包间转移；「背包全部入库」保留装备和安全箱，仓库空间不足时整批留在原处。「整理仓库」合并相同类型且救济标记一致的物品，大件优先排布并可旋转；不能排下时保留原布局。

搜刮界面双击来源物品放入背包，也可选中后点击「拿到背包」；部分堆叠装满后余量留来源。完整物品拖到单件其他物品上，双方都放得下才交换；拆分物品不交换。枪械可以直接拖到主武器槽，或选中后点击「装备主武器」或主武器槽；换下的枪和弹匣余弹放回背包，背包放不下时整笔不换。
