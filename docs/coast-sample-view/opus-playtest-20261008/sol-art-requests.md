# 给 Sol：第二批图片规格（Opus 试玩整改后）

2026-10-08。本清单承接 [试玩整改报告](README.md)。**只是规格，本轮没有生成或修改任何图片**；何时制作由用户另行指令。现有 43 件素材全部继续使用，ID、尺寸、锚点、SHA 不变。

## 先说明本轮在运行时做的三件事

这三件事会影响新图的画法：

1. **手臂由运行时绘制。** 人形角色（玩家及拾荒者、盐枭、守潮人）的袖管是一条按瞄准角旋转的 4 px 条带：墨线、亮面、暗面、墨线。袖管从肩点画到武器图上已有的手套，**手仍然画在武器图上**。
   - 身体图**不要画前臂和手**，上臂可以画到肘部为止。
   - 肩点：以帧左上为原点，约在 (16 ± 4, 19)，即脚底向上 29 px。
2. **墙顶降亮度。** Sol 的 `wall-core` 在合成时乘以 `#8a8780`，平均亮度从 124 降到约 66。原因是墙顶比地面（沥青约 60、院地约 90、地砖约 109）亮时，1 格厚的墙会被看成可走的平台。
   - 新一版 `wall-core` 请直接按**平均亮度 60–72**交付，并在 manifest 写 `"capValue": "final"`。目前运行时还没有读取这个标记；Opus 接入新图时再改为：读到标记就不再相乘。
   - 边缘条（`wall-edge-*`）保持比墙顶亮，起轮廓作用。
3. **地面物品改用游戏自带的 24 px 物品图标**（与背包、基地同一套画法），外加 1 px 浅色描边和接地阴影。**地面物品不需要另出图。**

- 沿用第三轮的 manifest 与 `scripts/coast-import-assets.mjs` 流程（SHA-256、尺寸、锚点逐张校验）。新 ID 按 `coast-<部件>-v1` 命名。
- 验收以正式 `城中村试玩.html` 的实机画面为准：
  - `node scripts/coast-playtest.mjs` 生成的全流程截图；
  - `scripts/coast-sample-shots.mjs` 的四种尺寸截图；
  - 敌人在 1280×720 下站在暗沥青上应能一眼分清种类；
  - 握持类检查（样板门禁 V05）应继续通过。
- 本清单不要求一次做完。优先 P1；P2 可在 P1 之后单独交付。
