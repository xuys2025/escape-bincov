## 一、结算原因（R6-L1）→ 落幕

以前「放弃行动」和「战死」都是 `outcome: 'death'`，前端只能靠「玩家是否倒地」猜落幕文字。现在直接读 `services.settlement().reason`。

| reason | 落幕文字 | 画面 |
| --- | --- | --- |
| `extract` | 撤离成功 | 淡出 |
| `death` | 你倒下了 | 倒地动画，画面变灰，暗红幕 |
| `timeout` | 行动超时 | 暗幕 |
| `abandon` | **已放弃行动**（以前显示「行动失败」） | 暗幕 |
| 未知值 | 行动失败 | 暗幕 |

- 结算准备好之后，reason 就有了，写入失败也保留。所以「正在保存」和「重试保存」面板的标题也会写明是哪种结局，例如「撤离成功 · 正在保存结算」。
- 只改显示。发奖、扣除、`outcome` 和重试流程都没动；放弃仍按失败结算（W13 断言 `outcome === 'death'`）。
- 结算音效仍按原 `outcome` 播放：撤离播撤离和弦，其余播失败提示音。

## 二、伤害来源（R6-L2）→ 受击反馈与持续伤害读数

以前前端用 `damage >= 1` 区分「打击」和「流血/污染的每帧小额伤害」，阈值两边都会判错。现在全部按 `hurt.cause`：

| 表现 | 打击 `blow` | 流血、污染、缺水、饱食不足 | 生命上限下降 |
| --- | --- | --- | --- |
| 受击音 | 响，**无论伤害大小**（以前不到 1 点的打击不响） | 不响 | 不响 |
| 身体闪白、后仰、血雾 | 有 | 无 | 无 |
| 红色受击边缘脉冲 | 有 | 无 | 无 |
| 生命条下的读数 | 无 | 「流血 -1.2/秒」「污染 -0.5/秒」等，每种来源一条 | 「生命上限下降 -3.0」，显示 3 秒 |
| 屏幕边缘 | — | 按当前最大的来源着色（流血暗红、污染黄绿、缺水土黄、饱食不足褐色），随强度变深 | — |

- 读数是前端把每帧的 `damage` 按来源累加、平滑约 0.5 秒得到的每秒掉血量。停止后再保留 0.8 秒消失。
- 混合来源时，Runtime 会在同一帧发多条 hurt，读数逐条显示，合计等于实际掉血。
- 文字只用了游戏已有的说法（流血、污染、缺水、饱食不足）。内嵌字体子集里没有「饥」「饿」「脱」和全角负号；字体重新生成属于维护者操作，所以没有动字体。
- 敌人只有打击。他们的闪白和血雾也只在 `blow` 时出现。

## 三、命中归属（R6-L3）→ 命中标记

- 命中标记改为只看 `impact.owner === 'player'`，删掉了前端自己记的「玩家子弹编号表」。
- 原有边界不变：命中点在未揭示房间里时不显示标记；事件仍按 stamp/epoch 过滤。
- **声音边界同步收紧：** 命中声和子弹打墙声，以前在未揭示房间里也会响，等于泄露了里面有人。现在与画面一致，不揭示就不响。枪声本身仍然听得到（枪声隔墙可闻）。

## 四、涨潮范围（R6-L4）→ 潮水画面（设计验收 G05）

`frame.flooded` 给的是当前地图「现在被潮水淹没的格子」。前端只按这个列表画水，不从地形码推断。

**画法（新增 `src/coast-view/tide.ts`）：**

- **三种地面可区分：**
  - 低潮时的泥滩：原有的泥地；
  - 高潮时的潮水：浅一些、偏灰绿的水面，有淤泥色块和细波纹；
  - 永久海水：原有的深蓝灰色。
- **岸线：** 淹没格与干地相邻的一侧画一道断续的浪花边，画在格子内部；与永久海水相邻的一侧不画，潮水和深海直接相接。浪花边随画面时间缓慢起伏。
- **层级：** 潮水在地面之上，在地面物品、尸体、阴影和雨之下。细雨落在潮水上会有雨圈和反光，和海面一样。
- **涨潮、退潮：** 涨潮在 0.9 秒内渐显，退潮在 1.4 秒内渐隐，之后不再保留任何格子。下面三种情况直接显示当前状态，不做渐变：
  - 进入或读档后的第一帧；
  - 换层；
  - 系统设置了「减少动态效果」。
- **困在水里的人：** 涨潮时如果有人（玩家或可见的敌人）还站在淹没格里，脚下画一圈水带盖住靴子，阴影隐去，走出去即消失。检查点规则允许这种位置。
- **水下的物品：** 落在淹没格里的地面物品变暗、偏灰绿、半透明，也不再闪光。高潮时人走不进去，所以拿不到。
- **地图面板：** 当前所在楼层的潮汐格改按 `flooded` 着色（与原高潮配色一致）。

潮汐格都在沿海地图东侧（x 63–69 一带和 y 37–38 的水沟），不在已装修的城中村街口内，所以那里的地面仍是通用占位画面。
