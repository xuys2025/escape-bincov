# 城中村样板第六轮：前端体验整改（Opus）

2026-10-09（UTC+8）。原分支 `docs/coast-2-5d-art-design`，从 `1c1c935`（第五轮之后的声音接通）接手；本地基线已含最新 main `841e8bb`，PR #22 远端头仍是 `878f563`。

用户指令：接手当前任务分支，自主完成前端界面、渲染、交互、动画、声音接入和整体体验整改；玩法逻辑、Runtime 接口、存档事务、图片生成和独立复验由 GPT 侧负责。本轮只改前端和共享的合成音频服务，**没有改 Runtime、规则、AI、存档协议或事务**，也没有生成图片。单文件离线不变（0 外部请求）。只做本地提交，没有推送、合并或发布。

**试玩入口不变：** 双击仓库根目录的 `城中村试玩.html`，点「进入水产站」，种子留空，点「出击」。

- 画面里默认有细雨。想看无雨的阴天，打开 `城中村试玩.html?weather=clear`。跳转页会把参数转给游戏，等同于游戏地址加 `&weather=clear`。
- 系统开启「减少动态效果」时，自动关闭雨点、碎屑、水面反光和镜头后坐，只保留静止的雾。

## 1. 接手时的问题

从第五轮的截图和真实输入全流程出发，按「出生 → 行进 → 交火 → 搜刮 → 撤离或倒下」逐段看，主要问题是：

| 方面 | 现象 | 原因 |
| --- | --- | --- |
| 地面 | 街面像电视雪花，并且按 32 px 一格明暗交替，像棋盘 | Sol 的沥青 b 比 a 亮约 10 级、噪点多一倍，按格随机取 a/b；两张都是单像素白点 |
| 墙 | 墙顶像一排灌木；立面像迷彩 | 墙顶贴图的大块浅斑在降暗后成了树丛状；立面剥落斑对比太强 |
| 光照 | 无顶废墟里有一块块硬边的亮暗矩形 | 室内光用「建筑外框内缩 32 px」的矩形直接填色 |
| 氛围 | 画面静止，除了人物没有任何动的东西 | 没有天气、空气、水面的动态 |
| 战斗反馈 | 打中没有确认，被打只有方向条；换弹只有文字；画面外开枪完全不知道方向 | 只有原版的受击方向条 |
| 导航 | 选了撤离点后只有右上角一行方位文字 | 没有指向标 |
| 结局 | 玩家被打倒只显示 1 帧就切到结算页（OPUS-DEATH-02） | 结算提交后宿主立即停止绘制 |
| 声音 | 所有声音都在正中、音量不变；从暂停菜单放弃时失败提示音被吞掉 | 合成音频没有声像；恢复音频期间提示音被静默丢弃（已登记缺陷） |
| 楼层 | 二楼、地下室地板上画着街面的井盖、雨水箅和车道线 | 这些街道装饰按固定格子坐标画，没有限定在沿海地图 |

## 2. 本轮做了什么

### 2.1 地面与墙（烘焙一次，不增加每帧开销）

- **Sol 素材柔化：** 运行时把每张环境素材向自身均值收拢，保留像素簇、去掉单像素噪点；沥青 a/b 统一到同一亮度。柔化表在 `src/coast-view/art/sol.ts` 的 `SOFT`。新图达标后删掉对应条目即可（见任务清单 R6-A1 至 A4）。
- **大尺度磨损和潮湿斑：** 用每张地图预先算好的值噪声格（72 px 与 22 px 两层），以 2 px 像素簇和 4×4 有序抖动量化。打破 32 px 的格子感，又不引入平滑渐变或模糊。
- **墙脚接触阴影：** 地面与墙接触的地方按距离分三档压暗，墙脚下有零星盐渍。墙不再像浮在地上。
- **投影：** 改成整块遮罩，再统一相乘：实心本影加两圈抖动半影。相邻墙格不会重复压暗出条纹。
- **水洼：** 只在室外沥青、偏向路缘的位置。外观是湿暗的水面、抖动的潮边和零星天光反射，不画左上高光（否则看起来像石头）。
- **墙顶：** 加压缝和缺口；立面加顶部亮线、潮湿的墙脚，部分外墙有锈迹或水痕。
- **街道装饰：** 井盖、雨水箅、车道线只画在沿海地图上，车道线有磨损缺段。楼层上的错位装饰随之消失。

### 2.2 光照

- 环境光改为每张地图烘焙一张低分辨率光照图（8 px 一格、线性采样）：室外是天光，有顶的室内是室内光，无顶废墟介于两者之间；轻度模糊，让光从门口漫进去，不再有硬边矩形。
- 立着的物体（墙、人、箱子）的染色从同一张图采样，所以墙和它前面的地面亮度一致。
- 房间灯有轻微的明暗起伏，偶尔闪一下。只看视图时间，不带状态。
- 地下室的环境光更暗。

### 2.3 空气与天气（`src/coast-view/weather.ts`）

- **细雨：** 雨点落点按世界坐标分槽，每个周期用稳定哈希重新取位置。镜头移动时雨点不跟着漂，也没有任何粒子状态。
  - 落在有顶建筑上时，雨点画在屋顶高度；一旦该房间被揭示（玩家在里面），就不画。
  - 雨棚下、墙上、楼层里都没有雨。
  - 落在路面是溅点，落在水洼和海面是一圈涟漪。
- **海雾：** 两层抖动的雾，随风缓慢飘移，按整像素移动，不会闪烁。
- **碎屑：** 偶尔有纸片和落叶被风吹过画面。风从海上来，所以雨、雾、碎屑都向西飘。
- **海面：** 每个可见的水格有一道缓慢明灭的反光。

以上全部只是视图时间和镜头的函数：同一批数据在同一视图时间重绘，像素完全一致（门禁 V07 验证）。不读取、也不改变模拟。

### 2.4 战斗反馈

- **命中标记：**
  - 玩家打中目标时，在命中点（胸口高度）弹出小叉；击杀时是更大的红叉。
  - 命中点在未揭示房间里时不显示，不泄露信息。
  - 近战命中同样有标记。
- **后坐：**
  - 镜头沿射击反方向轻踢（霰弹枪最大），准星同时放大一下；随机抖动减小。
  - 枪口冒一小团向上飘的烟。
- **换弹环：** 换弹时准星外圈按进度填满。
- **受击边缘：**
  - 每次实打实的伤害，屏幕边缘泛红一次，然后在约 0.6 秒内退去。
  - 生命低于 35% 时，边缘持续缓慢搏动；低于 30% 时还有心跳声。
  - 流血、污染的每帧小额伤害不触发。
- **画面外开枪：** 有人在画面外开枪时，屏幕边缘出现指向他的橙色箭头，0.9 秒淡出。只对室外或已揭示区域里的射手显示（对应 ASTRA-RANGE-01：敌人射程大于镜头纵向半高）。
- **其他：**
  - 冲刺时脚下扬起尘土。
  - 新尸体下的血泊约 3 秒内慢慢扩开；读档或后来才看到的尸体，血泊直接是完整大小。
  - 血泊同样按区域揭示规则显示。

### 2.5 交互与导航

- **撤离指向标：** 在地图里选了撤离点后：
  - 撤离点在画面外：屏幕边缘出现一个箭头，指向它，并写着名称和直线距离（格）。
  - 撤离点在画面内：上方出现一个上下浮动的标记。
  - 标记会避开状态卡、武器卡等界面；如果撤离圈本身已在画面里，但标记会压到界面卡片，就干脆不显示。
- **物资箱：** 搜刮面板打开时，箱盖是掀开的；关上面板后恢复。
- **门：** 东西向的门开关时，会经过约 0.1 秒的半开帧。
- **淡入：** 每次进入行动、换层、读档都从黑场淡入（第一次进入也有）。
- **短屏：** 在 640×300 这类很矮的屏幕上，状态卡只保留生命条和体力条；流血或污染时，状态行仍会显示。

### 2.6 结局落幕（修复 OPUS-DEATH-02）

结算写入成功后，宿主不再立即停止绘制。它继续绘制最后一帧：

- 没有模拟，也没有新事件和子弹。
- 玩家的倒地动画、镜头、灯光和天气继续动。
- 同时拉下落幕。

| 结局 | 时长 | 画面 |
| --- | --- | --- |
| 倒地 | 1.7 秒 | 画面转灰、压暗，边缘暗红，出现「你倒下了」 |
| 撤离 | 1.15 秒 | 先停一下再渐黑，出现「撤离成功」 |
| 超时 | 0.9 秒 | 渐黑，出现「行动超时」 |
| 放弃行动 | 0.9 秒 | 渐黑，出现「行动失败」 |

之后进入原有结算页。结算在落幕开始前就已存盘，所以落幕不影响存档；离开时会清掉复用画布上的滤镜。减少动态效果时，统一 0.4 秒。

### 2.7 声音

- **修复已登记缺陷「音频服务在恢复期间静默丢弃提示音」（`src/audio.ts`）：**
  - `resume()` 还没完成时请求的提示音，现在照常排定，等上下文一运行就播放。
  - 这个窗口最长 1 秒、最多 16 个声部，所以永远不会恢复的上下文也攒不出一阵爆音。
  - 原游戏从暂停菜单放弃行动时，死亡提示音回来了。
  - 样板撤掉了第五轮 150 ms 的延迟变通。
- **声像：**
  - 敌人的枪声、打在别人身上的击中声、子弹打墙、别人开的门，都按位置左右声像，并随距离减弱。
  - 玩家自己的声音保持居中、满音量。
  - 这些是 `SynthAudio` 新增的可选参数，原游戏的调用不变。
- **新提示音：**
  - 子弹从身边 30 px 内掠过时的掠空声。
  - 打在墙或门上的撞击声。
  - 空弹匣且没有备弹时扣扳机的空响。
  - 低血心跳。
  - 物品入包：在原拾取和弦下加一声短促的布料摩擦。原拾取音太轻，输出端测量时与海浪环境声几乎一样大。
- **室内闷声：** 在室内（已揭示的房间或楼层），海浪环境声的低通频率降下来，听起来像隔着墙。
- **试过又撤掉的雨声底噪：** 我试过给细雨加一层持续的嘶声。输出端测量显示，它会盖住轻的拾取提示音（音频测试 A5 在三次中失败一次）。界面反馈比氛围更重要，所以细雨只保留画面。

### 2.8 性能

- 地面每张地图只烘焙一次，并在整个视图生命期内保留：一局只有沿海图和两个小楼层，合计约 16 MB。从楼上回到街面不再重烘焙。
- 首次进入时，只同步烘焙起始视野附近的块；其余块在镜头接近到 320 px 以内时每帧烘焙一块。玩家从不靠近的块永远不烘焙。

本机实测（桌面 GPU，1280×720，Chrome 154；AI 运行时）：

| 项 | 第五轮之后（`1c1c935`） | 本轮 |
| --- | --- | --- |
| 首次进入沿海图的重建 | 每次重建都重画整张地面，约 26–32 ms | 170–215 ms（只在首次） |
| 从二楼回到街面的重建 | 26.5 ms | 约 20 ms（不再重画） |
| 同图重建，并换到新的位置 | 31.6 ms | 53–66 ms（含新进入视野的块） |
| 每帧视图提交 p50 / p95 / p99 | 第二轮实测 1.0 / 1.5 / 2.0 ms | 0.8–1.0 / 1.3–2.1 / 1.9–3.3 ms |
| 每帧 Runtime advance p50 / p95 | — | 2.7–2.9 / 3.9–4.2 ms（Runtime 未改） |

说明：

- 首次进入比原来慢，因为地面现在逐像素着色；读取画布像素本身就占了大头。
- 两次测量的区间见 [perf.txt（已归档）](../../IMPLEMENTATION-ARCHIVE.md)。
- 视图提交不含 GPU 完成时间，也不是手机数据；手机上的实测见任务清单 R6-V5。

### 2.9 测试与脚本

- **新增样板门禁 5 项，样板门禁由 37 项变为 42 项。** 这 5 项在 `1c1c935` 上运行全部失败（0/5）。
  - **V06 战斗反馈：**
    - 用真实鼠标射击，每次命中都恰好标记一次，且标记落在目标胸口 28 px 内；击杀有一次大标记。
    - 未揭示房间里的命中不标记。
    - 换弹环随时间填满。
    - 受击边缘会升起，然后退去。
  - **V06b 指向标：**
    - 撤离点在画面外时，边缘箭头的方向与撤离点误差小于 0.05 弧度，且不压住任何界面卡片。
    - 站在撤离点附近时，标记位于撤离圈正上方。
    - 撤离圈已在画面内、但被顶部界面挡住时，不显示指向标。
    - 画面外的射手会让顶边出现朝上的箭头。
  - **V07 空气无状态：**
    - 同一视图时间重绘两次，中间推进 0.5 秒，像素完全相同。
    - 对照：60 ms 后的画面必须不同。
    - 已揭示房间内没有雨。
    - 楼层上没有天气。
    - 回到街面不重烘焙。
  - **V08：** 搜刮时箱盖打开；开门经过半开帧。
  - **V09 玩家倒地落幕：**
    - 结算提交后仍持续绘制，先倾倒、后出现尸体。
    - 落幕期间宿主没有推进 Runtime。
    - 落幕文字是「你倒下了」。
    - 复用的画布上没有残留滤镜。
- **找到历史截图异常的根因：** `coast-sample-shots.mjs` 的 window 场景把玩家摆在 (360, 342)，与西墙重叠。存档校验拒绝这个位置，所以这个场景期间只要发生一次自动检查点，后面每张截图都会是「存档损坏或版本不兼容」的暂停面板。是否出现，取决于检查点时机。
  - 在 `1c1c935` 上用同一摆放直接调用检查点，同样被拒绝。
  - 现改为 (368, 344)。
  - 这很可能就是第二轮起记录的「未复现的存档保存失败」截图异常（ASTRA-SAVE-01），交 GPT 确认（R6-V4、R6-L5）。
- **`coast-audio-test.mjs` E2 改为按电平判断：** 服务修好后，死亡提示音与环境声在暂停后的第一个渲染块同时开始，起音检测没有前文可比。现在比较结算窗口的峰值与提示音结束后环境声的峰值。
  - 判断条件：至少 1.6 倍，且峰值大于 0.09。
  - 实测：有提示音的 16 次是 2.11–2.89 倍，峰值 0.113–0.159；提示音被吞掉时（修复前的原游戏），两个窗口都在环境声水平（约 0.05，约 1 倍）。
  - 校准经过：我最初定的是 2.2 倍，正好落在「有提示音」的范围里。正式验证 3 次中有 2 次因此未达标（2.19 倍、2.11 倍），但提示音实际都响了。按上面的分布改为 1.6 倍后，在同一正式构建上复跑 3 次，都是 14/14。全部数据见 [audio-e2-calibration.json](evidence/audio-e2-calibration.json)。
- **`coast-playtest.mjs`：** 等落幕结束、样板卸载后再截结算页，并多截一张落幕。
- **`tests/coast-sound.test.ts`：** 由 5 项扩为 9 项，覆盖声像、掠空声、心跳、空响、室内闷声，以及结算提示音不再延迟。单元测试共 233 项。

## 8. 补充：试玩反馈的两处修复（2026-10-09）

用户试玩 `0a5e3da` 后报告了两个问题。两处都是第六轮样板面板自己的前端缺陷，基地界面没有这个问题。

### 8.1 格子里的物品名被截成「保...」

- **原因：** 样板的背包和搜刮面板把格子缩成了 44 px（触屏和矮屏 36 px），比基地界面的 54 px 小。
  - 物品名用 16 px 的点阵字，三个字要 48 px，44 px 的格子只剩约 40 px。
  - 九件 1×1 物品的名称是三个字：保险管、卡宾弹、除藻剂、力量针、体质针、技巧针、护身符、残护符、潮香包。它们都会被截断。
  - 触屏 36 px 时，连「9mm」也会被截断。
  - 第五轮把这一项记成「要和基地界面一起改」，判断错了：基地界面一直是 54 px，只有样板的面板缩小了。
- **修复：**
  - 桌面改用基地界面的 54 px。三个字用原生 16 px 点阵字完整显示。
  - 触屏是 40 px，很矮的桌面窗口（高度小于 600）是 44 px。这两种情况下，放不下的名称改用 11 px 系统字体显示全名，不再截断。

### 8.2 拖动物品时面板出现滚动条

- **原因：** 拖动时跟随鼠标的物品影子是「固定定位」，却放在了停靠面板里面。面板用 CSS transform 居中，浏览器因此把影子当成相对面板定位：
  - 影子落在离鼠标几百像素的面板外面；
  - 面板的可滚动范围被撑大，于是出现滚动条。
  - 放下物品的判断用的是鼠标坐标，所以拖放结果本身是对的。原来的拖动检查只检查结果，没有发现这个问题。
- **修复：** 影子改放到样板根节点下（固定定位，没有 transform）。现在影子跟着鼠标，面板不再溢出。顺带解决了一个隐患：拖动途中面板如果重绘，影子不会再被清掉。
- **收尾：** 影子不在面板里以后，面板关闭时要主动移除它。
  - 按 Tab、Esc、E 关闭，窗口失焦暂停，或进入结算，都会走同一个清理入口；
  - 面板重新打开时，或开始新的拖动之前，会先清掉上一次没收到松手事件的影子。

### 8.3 检查

新增 6 项样板门禁，样板门禁共 48 项：

- **U11（四种尺寸）：** 把四件三字物品经真实存档会话放进安全箱后打开背包，所有物品名都不能被截断；桌面用点阵字，触屏用紧凑字体。
- **U12（1280×720、1920×1080）：** 在背包和搜刮面板里用真实鼠标拖到屏幕右边和底边：
  - 影子左上角始终在「鼠标减抓取偏移」1.5 px 以内；
  - 影子不在面板里，并且画在面板上层（对影子左上角做命中测试）；
  - 面板没有任何溢出；
  - 松手后影子被移除；
  - 拖动途中按 Tab 关闭面板，或窗口失焦暂停，影子随面板一起消失。

在 `0a5e3da` 上，这 6 项全部失败（0/6），失败原因与用户报告一致：

- 保险管在 42 px 宽的格子里被截断；
- 触屏时「9mm」也被截断；
- 拖动时面板溢出 67 px（1280×720）和 427 px（1920×1080），影子离应在的位置约 316 px 和 768 px，已经落到屏幕下沿之外，所以玩家拖动时看不到影子，只看到滚动条。

修复后 6/6。证据见 [fix/](evidence/fix/)：

- 截图：修复后的物品名（桌面 1280×720、触屏 844×390），以及拖动途中影子在搜刮面板上层；
- 新旧两版的门禁记录：`gates-on-0a5e3da.json`、`gates-new.json`；

另外记录一点：在 640×300 这种极小的横屏上，背包面板本来就需要上下滚动。旧版溢出 153 px，现在因为格子从 36 px 改为 40 px，溢出 173 px；844×390 两版都不溢出。这是屏幕高度不够，不是本次的拖动问题。
