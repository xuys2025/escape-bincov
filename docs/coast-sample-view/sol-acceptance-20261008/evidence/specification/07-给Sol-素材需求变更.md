# 给 Sol：素材需求变更（相对 03 图片规格清单）

本轮根据 A01 核对到的真实规则修正了原型：拾荒者是近战，盐枭和守潮人用长枪，玩家另有霰弹枪和匕首，世界物资按类别显示。下表只列**变化**；未提到的条目仍按 [03-给Sol-图片规格清单](03-给Sol-图片规格清单.md) 执行（独立 1× PNG、真实 Alpha、边界坐标锚点、32×80 墙段）。

**本轮不批量制作。** 先交第 4 节的首批试样，前端在原型里实测并反馈后再扩量。

## 1. 新增与修改

| 变化 | 素材 ID | 规格 | 说明 |
| --- | --- | --- | --- |
| 修改 | `coast-weapon-pistol` | 16×8，握持 (3, 4)，枪口 (15, 4) | 枪管轴线必须落在第 4 行 |
| 修改 | `coast-weapon-carbine` | 31×10，握持 (8, 4)，枪口 (28, 4) | 同上 |
| 新增 | `coast-weapon-shotgun` | 31×10，握持 (9, 4)，枪口 (28, 4) | 双管、木枪托和护木，两只手 |
| 新增 | `coast-weapon-knife` | 16×7，握持 (2, 3)，刀尖 (14, 3) | 近战挥砍由运行时旋转实现，不需要挥砍帧 |
| 新增 | `coast-weapon-club` | 20×7，握持 (2, 3)，末端 (18, 3) | 拾荒者的铁管或棍棒，末端带锈 |
| 新增 | `coast-weapon-rifle` | 31×10，握持 (8, 4)，枪口 (28, 4) | 盐枭和守潮人的长枪；枪身加锈红布条，便于与玩家卡宾枪区分 |
| 修改 | 人物 `scav` | 同 32×48 | 不持枪；面罩或围巾保持锈红 |
| 修改 | 人物 `elite` | 32×48，5 方向 × 7 帧 + 尸体 = 36 帧 | 头盔、护甲板、锈红臂章；全沿海必需，城中村样板可排后 |
| 新增 | `coast-loot-note` | 16×14，锚点 (8, 11) | 地面告示纸张，对应地图 `notes` |
| 修改 | `coast-loot-*` | 16×14，锚点 (8, 11) | 固定 7 类：`ammo`、`medical`、`valuable`、`material`、`weapon`、`quest`、`note`。前端按物品 ID 映射到类别，不为每个物品单独做图 |
| 新增 | `coast-ground-water` ×4、`coast-ground-mud` ×3 | 32×32，不透明可平铺 | 经典深水（地块编码 2）画成水面，不画成墙；潮汐浅滩（编码 4）画成泥滩。城中村样板用不到，全沿海前交付 |
| 确认 | 屋顶模块 | 不变 | **二层条带 `coast-storey-*` 必须与屋面模块分开交付**。玩家在高楼北侧时，前端会收起条带、把屋面降到一层高度，此时屋面单独就要完整盖住室内；屋顶杂物（水箱、楼梯间）只能放在屋面上，不能挂在条带上 |
| 确认 | `coast-ceiling` | 32×32 | 楼上未揭示房间的暗色楼板 |

## 2. 不需要交付

以下由运行时生成，Sol 不用画：

- 换弹姿势（枪口下压）、近战挥砍弧线、受击闪白、受击后退位移。
- 撤离进度环、受击方向指示、交互描边、遮挡轮廓、各级抖动淡化。
- 霰弹枪的大号枪口火（复用枪口火两帧，运行时放大）。
- 火花、血点、弹壳、尘土，以及尸体下的血泊图样。

## 4. 首批试样（建议一次只交这些）

1. **player**：5 个方向 × 站立 1 帧 + 步行 4 帧，共 25 帧。前端检查脚底基线、方向切换是否抖动、镜像效果。
2. **墙体**：墙芯 ×1、四条压顶边、室外立面 ×2、室内立面 ×1、`window-ew` ×1、`door-ew` 关/开。
3. **地面**：柏油 ×2、院落 ×2、瓷砖 ×2。
4. **武器**：carbine 1 件，用于核对握持点、枪口点和枪管轴线。

前端收到后放进原型（`?test=1` 的「街口全景」「门口」「贴窗射击」），给出逐项反馈后再扩量。

## 5. manifest 字段补充

除 03 列出的字段外：

- 武器加 `grip`、`muzzle`（边界坐标）和 `axisRow`。
- 世界物资加 `category`。
- 人物加 `kind`、`dir`（E / SE / S / NE / N）、`frame`（idle / walk1–4 / fall1–2）、`baselineY`（应为 48）。
- 屋顶模块加 `part`（surface / storey / prop）。

资源 ID 继续与存档实体 ID 分开。
