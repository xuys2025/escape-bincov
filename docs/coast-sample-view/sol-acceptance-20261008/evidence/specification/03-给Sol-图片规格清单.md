# 给 Sol：图片规格清单（O00 → S01/S02）

> **2026-10-07 变更：** 武器、敌人持械、elite、世界物资类别、水面/泥滩等调整见 [07-给Sol-素材需求变更](07-给Sol-素材需求变更.md)，以 07 为准；本轮不批量制作，先交 07 第 4 节的首批试样。

这份清单以原型的实际渲染方式为准。原型里的程序占位图（`src/view/art/*.ts`）就是每个槽位的尺寸与构图参考：先打开 `dist/index.html` 看效果，再对照下表交付。PR #22 的提示词模板、拼板流程和淘汰条件继续适用。

## 1. 通用规则

| 项 | 要求 |
| --- | --- |
| 交付形式 | **每个素材一张独立 PNG**，按 1× 逻辑像素交付；运行时由前端打包图集，Sol 不需要做图集和隔离边 |
| 透明 | 真实 Alpha；除标注为“阴影”的素材外，Alpha 只有 0 或 255，不能有半透明抗锯齿边 |
| 视角 | 正俯视方格地面 + 向上延伸的南立面；没有透视、没有菱形等距 |
| 光照 | 左上主光：顶面与左缘亮、右缘与下缘暗。**不画投影**（接地影、墙体投影、光照都由运行时生成）；可以保留接触缝的暗线 |
| 色板 | PR #22 基础色板；每种材质 3–5 档；敌对角色必须带锈红识别色（#8c4a3a 一档），玩家带暖黄臂章（#c9a65e 一档） |
| 文字 | 图上不出现任何文字、编号、标志；招牌只画空白底板 |
| 运行时自动生成，不用交付 | 抖动淡化档、受击闪白、遮挡轮廓、交互描边、粒子（火花/血点/弹壳/尘土）、光照 |
| 命名 | `coast-<类别>-<名称>-<变体>-v<版本>`，例如 `coast-wall-ext-plain-a-v1`；方向帧加 `-e/-se/-s/-ne/-n` 与 `-f0..f4` |
| 清单 | 每批附 `manifest.json`：`id`、文件名、宽高、锚点、层（ground/flat/upright/upper/decor）、方向与帧、对应逻辑实体或“纯装饰”、SHA-256、原图文件、提示词 |

锚点统一用**画布边界坐标**（右下角是 (w, h)，不是像素索引）。

## 3. 墙体与门窗（层：upright，**32×80**，锚点 (0, 80)，即左下角对齐该格南边界）

墙段画布上 32 行是顶面（墙厚一整格），下 48 行是南立面。顶面四边的“压顶亮边”按相邻关系出现，所以顶面拆成可组合的部件：

| ID | 尺寸 | 说明 |
| --- | --- | --- |
| `coast-wallcap-core-{a,b}` | 32×32 | 墙芯中暗色（约 #46433d），细碎斑点 |
| `coast-wallcap-edge-{n,e,s,w}` | n/s 32×3，e/w 3×32 | 外露边的浅色压顶（n、w 亮；e 暗；s 亮线）；运行时按 4 邻接组合 |
| `coast-wallcap-ruined-{a,b,c}` | 32×32 | 台风掀顶残墙：压顶缺口、残留铁皮条（只用于无屋顶建筑） |
| `coast-wall-ext-{a,b,c,d}` | 32×48 | 室外立面：灰混凝土砌块、檐口亮边、墙脚 9px 潮湿带与盐渍；变体为锈水痕、裂缝 |
| `coast-wall-int-{a,b,c}` | 32×48 | 室内立面：灰白抹灰 + 下部 18px 绿灰墙裙 |
| `coast-wall-window-ew` | 32×48 | 东西走向墙上的窗（人从南面看）：暗玻璃、窗台、**防盗网**；窗洞宽 24 |
| `coast-wall-window-ns` | 32×32 | 南北走向墙上的窗（俯视墙顶）：顶面中间 16px 宽玻璃槽 |
| `coast-door-ew-{closed,open}` | 32×48 | 门洞 22×44 居中；开启态门洞**完全透明**，门扇贴左门框成 4px 窄条 |
| `coast-door-ns-{closed,open}` | 32×80 | 墙中线上的门扇：关闭为 8px 宽木条（顶面 + 立面），开启只留合页柱与门槛；其余透明 |
| `coast-lintel` | 32×80 | 两格宽门洞上方：顶面 + 5px 门楣，其余透明 |

门的开关外观只由已提交门状态决定；实际开口必须正好落在原逻辑格内，不能把门画进相邻格。

## 4. 矮物（层：upright，32×48，锚点 (0, 48)：顶面 32 + 正面 16）

对应逻辑 `low` 格（挡人不挡视线/子弹）：灶台 `coast-low-stove`、桌 `coast-low-table`、床 `coast-low-bed`、柜 `coast-low-cabinet`、柜台 `coast-low-counter`。每件占满一格，不能画成高柜。

## 7. 人物（层：upright，32×48，锚点 (16, 48) 即脚底中点）

| 项 | 要求 |
| --- | --- |
| 种类 | `player`、`scav`、`salt`、`elite`、`creature`（感染体，佝偻宽矮，剪影必须和人类明显不同） |
| 方向 | 交付 5 个：E、SE、S、NE、N；W、SW、NW 由运行时水平镜像。所有方向脚底同一基线，身高一致（头顶约 y=9） |
| 帧 | 站立 ×1、步行 ×4（第 1、3 帧跨步并下沉 1px）、死亡过渡 ×2（踉跄、跪倒）；之后由尸体图接替 |
| 身体 | **不含武器和握枪的手**；保留肩部。身体不会整图旋转，武器层独立按连续角度旋转 |
| 识别 | 敌对：锈红面罩/围巾；玩家：暖黄臂章；盐蚀者：浅色外套与盐壳白点；精英：头盔与护甲板 |
| 尸体 | `coast-corpse-<kind>`，40×24，锚点 (20, 14)，头朝右平躺；朝左由镜像。不能是直立图旋转 90° |

## 10. 城中村样板 P0（首批）

按此顺序交付即可替换原型中的全部占位图：

1. 地面：柏油 ×4、院落 ×4、瓷砖 ×4、水泥 ×2、路缘全套、井盖/箅子/标线。
2. 墙体：墙芯 ×2 + 边条 4 件、室外立面 ×4、室内立面 ×3、残墙顶 ×3、两种窗、两种门各两态、门楣。
3. 矮物：灶台、桌。
4. 屋顶：9 宫格 + 补丁 ×2、二层条带 ×3、水箱、楼梯间、雨棚 3 件。
5. 装饰：空调、雨水管。
6. 人物：player、scav、salt、creature 各 5 方向 × 7 帧 + 尸体（共 4×35 + 4 = 144 帧）。
7. 武器：手枪、短卡宾；物资箱满/空；散落物 ×3；枪口火 2 帧；楼梯 2 件；撤离标识。

角色帧最多，建议按“一个角色一张 5×7 方向帧板”生成，先用 player 做试样，确认基线与方向一致后再扩到其他角色。

## 11. 交付后的检查（前端负责在场景里验收）

- 原尺寸与 2×/3× 最近邻检查；墙段相邻接缝、墙顶边条组合后无断线。
- 人物在原型中走动检查：方向切换不抖动，步行帧脚底不滑动。
- 门窗开口与逻辑格对齐（原型打开 `?debug=1` 可直接看到逻辑格叠加）。
- 发现问题时，前端会给出素材 ID、方向/帧、实际截图和问题描述，只返修该项。
