# 中国大陆网络下在线游玩：部署调研

核对日期：2026-10-04。对应版本：0.1.1。

本次公开发布采用 [GitHub Pages 试玩](https://xuys2025.github.io/escape-bincov/)，维护步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。下文的 EdgeOne 是面向大陆访问的备用部署方案；尚未开展大陆三网实测，也未部署 EdgeOne 镜像。

## 结论

现有游戏可直接作为静态网站上线，玩家打开链接即可在桌面浏览器单人游玩。游戏逻辑、Phaser、样式、程序图形和合成音效均已包含在约 1.51 MiB 的 HTML 内，无需游戏后端、数据库或外部 CDN。在线托管不改变现有键鼠操作，也不增加手机触控、多人联机或云存档。

如果需要面向大陆访问的备用入口，可用腾讯 EdgeOne Pages（当前部分文档称 Makers）的静态托管，绑定自有域名。尚无已备案域名时，选择“全球可用区（不含中国大陆）”用于先期试玩；已有已备案域名且希望使用大陆节点时，再选择中国大陆或包含大陆的加速区域。这是根据平台文档和本项目结构提出的选择，EdgeOne 镜像尚未部署，也没有大陆移动、联通、电信的实测数据。

## 方案对比

| 方案 | 条件与特点 | 适用情况 |
| --- | --- | --- |
| EdgeOne 静态托管 + 自有域名 + 不含大陆的节点区域 | 官方文档不要求此区域的自定义域名具备 ICP 备案；托管无需自行维护服务器。跨境线路的实际表现须测量 | 先让朋友通过固定链接试玩 |
| EdgeOne 中国大陆／包含大陆节点 + 已备案域名 | 平台要求域名先完成 ICP 备案，能使用大陆节点 | 后续面向大陆玩家的长期访问 |
| 香港轻量服务器 + 静态 Web 服务 | 腾讯云明确香港服务器不要求 ICP 备案；需要自己维护服务器、证书与更新 | 已有香港服务器，或希望自行控制部署 |

腾讯官方有免费套餐入口，但不把当前促销价或额度视为长期保证；创建项目时以该账号控制台显示的产品套餐与配额为准。单个 HTML 足够，不必为当前版本额外租用数据库或游戏计算服务器。域名费用与托管费用分开。

平台对域名接入的备案要求，不等同于对游戏内容或运营资质的完整判定；正式面向公众运营时仍需按平台审核要求处理。

## EdgeOne 的具体上传步骤

1. 在 Pages／Makers 控制台创建项目，选择“直接上传”。
2. 填写项目名称，按域名备案情况选择加速区域。
3. 上传 `Escape-Bincov-web.zip`（从 [`main-latest` 发布页](https://github.com/xuys2025/escape-bincov/releases/tag/main-latest)下载，或本地 `pnpm package` 后在 `release/` 里）。其根目录直接包含 `index.html`，不需要解压源码、安装依赖或执行构建命令。
4. 部署后先用预览链接检查菜单、出击和声音。
5. 在域名管理中绑定一个固定的子域名，例如 `bincov.example.com`（示例，不是实际地址），按控制台指引添加验证及 CNAME 记录，确认 HTTPS 证书生效。
6. 用最终 HTTPS 域名验证本地存档、下载备份与导入；后续更新始终部署到同一项目和域名。

官方直接上传文档支持 ZIP／文件夹，单文件上限 25 MB、最多 1000 文件；本项目只有一个约 1.51 MiB 的文件，符合此限制。注意直接上传项目与 Git 自动部署是两种不同流程，官方文档说明后续不能直接把上传项目切换为 Git 集成，若需要自动部署须新建对应项目。

**不要把默认预览链接当永久游戏地址。** 官方域名文档规定，在中国大陆访问默认项目／部署域名时须使用系统生成的预览链接，链接有效期为 3 小时，过期返回 401；可在控制台重新生成。固定自定义域名才适合持续分享。

## 存档如何延续

0.1.1 已提供「水产站 → 导出存档／导入存档」。

- 从 0.1.0 升级：保留原浏览器和原 HTML 文件路径，将新版 HTML 覆盖到原位置，打开后先导出备份。
- 从本地迁移到在线：在本地导出 JSON；打开正式 HTTPS 游戏网址，在水产站确认导入。
- 更换域名、浏览器或设备：同样使用导出／导入。存档仍在玩家本地，网站管理员不会自动收到或同步存档。
- 正在行动时不提供完整存档导出；结算写入失败时，可从专用面板下载包含本次结算成果的备份。
- 普通版本更新维持同一 HTTPS 域名和端口即可继续使用该站点的本地存储。HTTP 与 HTTPS、不同主机名和端口对应不同 origin；`file:` 路径的行为依浏览器而异。

## 部署后的实际检查

在大陆移动、联通、电信各找一个真实网络，关闭代理后打开最终 HTTPS 地址，记录首次进入菜单用时、是否需要外部请求、是否能连续运行与恢复存档。当前游戏没有外部资源请求，因此网络主要影响首次 HTML 加载；进入游戏后的战斗不依赖远程服务器。关闭或刷新页面仍遵循行动中断规则，不能把网页缓存当作离线启动保证。

静态服务器应返回 `Content-Type: text/html; charset=utf-8`，不要使用附件下载的响应头。为 HTML 启用 gzip/Brotli，并使用允许及时更新的缓存策略；不要把可变的 `index.html` 设置成永久 immutable。不要在带存储限制的沙箱 iframe 中嵌入游戏。
