## 写作目标

让滨科夫的故事从设定清单变成值得阅读、能让人关心其中人物的叙事。可优先着力于县城生活的具体质感、灾后人的处境、人物之间的关系与矛盾，以及六阶段主线和三个结局的情绪积累。文学性的判断以实际文本为准，不靠增加修辞数量或篇幅完成。

叙述视角、结构、节奏和文体由后续作者发挥；本交接不预先代写故事。可以为人物补充经历、声音和生活细节，让不同势力的选择由具体人物与行动呈现。

## 设定与实施边界

以 #27 的已接受设定为起点：潮水封锁沿海县城、盐度与受盐、内陆区域扩展、现有势力关系、六阶段主线，以及逃离／封潮／留守三种选择。远汐号和失踪的第七艘船是不同对象；普通行动撤离回水产站，最终主线撤离才离开县城。

这些设定可在叙事中重新组织、充实和深化。如果更好的故事需要改变地图关系、据点数量、人物立场、剧情真相或结局条件，请在同一 PR 中明确列出取舍供维护者审阅。文学修订不能把新增游戏规则或 #26 中的未决建议写成已经确定、已经实现的事实。

本轮交付为故事文稿及必要的设定说明。玩法、地图、任务、盐度数值、存档、素材和发布的实际接入仍在 #22 完成后安排；文稿可以先行修订。#26 保持开放，文学重写不等于其中建议已全部解决。

## 续作与交付

作者可以直接重写原稿的叙事部分，也可以把故事正文放入独立文稿，让原设定文档保留地图、任务和实现边界的清晰索引。选择有利于阅读和后续开发的组织方式，避免出现两份互相矛盾的设定。

完成时在本 PR 提供重写文本和简要修订说明，指出保留、深化或提议调整的设定，校对人名、地名、时间线、主线线索和结局因果，并同步相关导航。维护者审阅文学效果后，再决定是否转为 Ready 和合并。

准备阶段仅建立交接入口、登记任务并创建草稿 PR，保留原故事正文供作者接手。纯文档准备只检查链接、事实和 Git 差异；不以游戏测试或 CI 成功替代文学审阅。

## 修订说明（2026-10-09，Opus 5.5）

### 组织方式

故事正文放入独立文稿 [MAIN-STORY.md](MAIN-STORY.md)，[世界观与地图主线](WORLD-REGIONS-STORY.md)继续作为地图、势力、任务节点与实施边界的唯一索引；该文开头加入文稿入口，新增第 6 节汇总文稿补充的人物与情节，避免两份设定各说各话。README 文档导航同步增加入口。

文稿用第二人称“你”，保留玩家身份的空白，只交代“台风前一天从西线国道进县”这一处来历，使逃离结局成为原路返回。结构为序章、六章、三个结局，每章依次写到该阶段的三个关键节点。文学处理的重点：

- **从清单到人物：** 五方势力和三个地方组织各由具体的人承担选择，例如封锁队的钟队长、旧院拾荒者的宋姐、盐枭中的船主林满仓与掮客鲍经理、守潮人中的顾阿婆与顾海生母子。
- **生活质感：** 用台秤、套袖、寻人黑板、铝饭盒、磅秤、访客登记簿等可想象的器物交代处境，避免每段以灯、潮声或盐雾收尾。
- **情绪积累：** “撤离的意思是回来”“出门的人，五点前回来”“听到了就按两下”“先别开封”在前文埋下，分别在三个结局中兑现。
- **沿用游戏文本：** 现有维修单、市场告示、观测站记录、港口值班笔记、三句任务电台（「让灯亮起来」只取前半句）和怀表停在 03:17 的描述原样进入故事，并给出不依赖超自然摆渡船的解释。

### 保留的设定

潮水封锁县城、窗口越来越短、盐度的来源与症状、受盐与守潮人分派、潮蚀生物不受统一指挥；一处水产站据点、十二个出击区域及其势力分布；五方势力关系与五类冲突（商场配给、工厂设备征用、医院救治、港口运输、国道撤离资格）；六阶段十八节点的顺序，以及三处沿用的现有任务；远汐号与第七艘船是不同对象；实验室放大了盐化但没有创造全部异常；灯塔异常物体放大潮水、干扰窗口，但不是最终答案；三个结局的最后行动与代价；普通撤离指回水产站，只有主线最终撤离离开滨科夫。现有任务名称、物品、敌人名称和“污染”术语均未改动。

### 深化的内容

见设定文档第 6 节：十三名主要人物及其经历；第九天大巴、第六十一天长退潮等叙事时间锚点；“七号”经泵房闸口进内河、因而无船主无泊位的运输路线；远汐号以“工业盐”名义运货、冷链设备厂检测车间作为实验室门面；母样“整件”在台风后经盐枭运往岬角；“守潮”原指渔民女人在台风夜等船；母样离开海水便安静，作为封潮行动的依据。

### 校对结果

- **人名与地名：** 老栓、许医生、小蔡、守潮人、盐枭、拾荒者、潮蚀生物、水产站各设施名称，以及南湾冰鲜、旧交易厅、海声修理铺、船工宿舍、红帆炸鸡、财务室、商场办公室，均与 `domain.ts`、`world.ts`、`mall-world.ts` 及设定文档一致；新增人物与现有名称不重名。
- **时间线：** 三十多年前旧院已有同症病例 → 九年前首次打捞与十一例病历 → 四年前实验室开门 → 三年前打捞续上、七号开始驳运 → 第 0 天台风 → 第 3 天老蔡最后领配给 → 第 6 天整件运往岬角 → 第 9 天大巴受困 → 第 17 天到站 → 第 18 天取回零件、次日恢复供电 → 第 20 天联系工厂 → 第 23 天首次看地峡 → 第五十几天清路 → 第 61 天长退潮。
- **线索链：** 生存链为工厂车辆—商场与市场补给—医院药品—水产站组织名单；异常链为打捞日志—远汐号货单—七号与船册—实验室接收与笔记—旧院病例—鲍经理账本与岬角。两条链在第五章的名单和第六章的长退潮汇合。
- **结局因果：** 逃离依赖第五章的车辆、柴油、药品、名单和窗口预测，玩家出县后由老栓掉头回县、孔主任留下；封潮依赖沈工“离开海水就会安静”的说明和顾阿婆带路，代价是玩家被涨潮截在岬角；留守依赖修好的净水、观测和卫生所，代价是放弃这次离开。

### 未改动与后续

本次只修改文档：没有改源码、任务、物品、数值、存档、素材或发布包，文稿里的人物和事件都还没有进入游戏。引用格式的新增广播与账目可以作为日后便笺、电台的候选文本，具体采用和接入仍排在 #22 之后。#26 中的医院据点、病区、持久盐度与异化路线未写入文稿，问题继续开放。

## 文学润色与去模板化修订（2026-10-10）

在 PR #29 故事骨架与主线因果获得批准后，本轮按文学审阅要求完成全篇去模板化修订：

1. **承接分支与边界：** 以已合并 PR #29 的最新 `origin/main`（`43a342c`）为基线，在独立任务分支 `docs/story-literary-polish` 上交付，不改动正在进行的 PR #30（剧情转化规格）、PR #22（美术设计）或 PR #28（改枪规划）。
2. **文本重塑重点：**
   - **剔除旁白越位解说：** 删除了原稿中各处在场景、动作已交代清楚后追加的抽象升华、概念定义或道德点题（如序章末尾对“撤离”字义的直接阐释、第二章对师徒恩怨的前情复述、第六章对名单代价的元总结）。
   - **对白动机与措辞贴地：** 人物对话不再充当作者背景设定的传声筒。严志强与老栓的交涉紧扣高压胶管、轴承进泥、买断工龄旧账与工厂设备存亡；沈工的对话去除了过于工整的哲理总结，还原为长期受盐导致的窒息、咳嗽与衰竭状态；小蔡的语言维持克制少言的年轻电工习惯。
   - **打破单一节奏模式：** 破除了“停顿/打量/摸出物件 → 短促金句定调”的单调拍子，改以现场机械阻力、身体症状、环境杂音与长短交替的叙事流推动情节。
   - **加深异常与生活秩序的冲突：** 封潮结局重写了顾海生贴近水池听女儿背《小石潭记》时的真实心理与生理撕裂，以及进水闸切断、池底排空时低频震颤抽离的物理断裂感，避免舞台化默契。
3. **设定与事实核对：**
   - 维持第二人称视角不变；
   - 严格保留主线六阶段十八节点与三结局设定；
   - 严格保留“远汐号”与“七号”船只区分；
   - 严格保留实验室放大机制、老蔡经历与位置、水产站至县外撤离层级；
   - 游戏现有任务、维修单、告示、电台广播等既定引用字句逐项完整保留。
