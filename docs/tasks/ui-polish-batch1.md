## 问题

2026-10-31 在 main `e3a7496` 上实际运行打包版本，两档桌面截图核对（检查清单见 [#163](https://github.com/xuys2025/escape-bincov/issues/163)）。第一批是改动小、玩家一眼能看到的五处：

1. **行动里的页面提示压住按键栏。** 页面提示 `#toast`（存档冲突、院子里刚弹的消息带进行动）固定在距底部 18px（`style.css`）。1280×720 下它盖住左下按键栏的“Esc 暂停”；打开背包时还盖住面板底部那行操作说明。
2. **院子面板最后一个页签被截。** 任务、设施、身体面板宽 560px，七个页签合计约 578px，“出击 7”只露出一部分。页签栏能横向滚动，但隐藏了滚动条，看不出还有内容。
3. **整备面板折行。** 左列只有背包宽（1280×720 下 216px），“携行重量 含装备与安全箱 2.8 / 24.0 kg”折成三行，“kg”单独一行；武器行“背包备用 32 发”的“发”单独掉行（`.slot span` 允许任意处断行）。小节编号是 01、02、安、03。
4. **结算页缩成小框。** 桌面只按整数倍缩放（`main.ts`），1280×720 取 1 倍，整页 960×540 居中，四周留宽黑边。
5. **院子快捷栏和交互提示不对齐。** 快捷栏贴右，交互提示居中。

核对后不改的三处：武器卡枪图尺寸（维护者 10-27 定的整数倍规则，见 `coast-view/host.ts` 的 `weaponIcon`）；“暴击 6.90%”两位小数（[暴击设计](../CRITICAL-PERK-DESIGN.md) 2.3 规定）；快捷栏“页签 0”和暂停菜单“切换到旧版页签”（10-10 决定旧页签保留为备用入口）。右上角“任务 · 0 项未完成”的措辞和 #161 改的是相邻行，等它合入后再改。

## 改动

只改显示，不碰规则、存档和输入。

1. 桌面行动中，页面提示抬到按键栏上方（距底 52px）；背包或搜刮面板停靠在底部时，再抬到面板上方。面板高度由宿主每四帧量一次（原来就为镜头量 `panelInset`），写进页面变量 `--cs-dock`，值不变时不重写，卸载时移除。手机行动保持原规则（触屏按钮上方）。
2. 页签按钮左右内边距 10px → 7px，标签和按键提示间距 5px → 4px；七个页签在 560px 面板里放得下，剩约 40px。
3. 携行重量：标签和数值同一行、数值不断行，“含装备与安全箱”放到下一行小字。武器行每项（弹匣、救济、背包备用）整体不断开，只在项与项之间换行。小节编号改为 01 主武器槽、02 背包、03 安全箱、04 仓库。
4. 桌面结算页和标题页一样铺满窗口：背景画铺满（等比裁切），结算卡仍按原整数倍放大（`--world-scale`），所以 1920×1080 下和原来一样大。手机结算页原来就铺满，不变。
5. 有键盘且窗口宽度 ≥900px 时，快捷栏居中，在交互提示正下方。更窄的窗口和触屏保持原来的靠右布局。
